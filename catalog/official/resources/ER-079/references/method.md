# 팀 실행 설계 Skill: 판단·처리 기준

inputs는 초기 입력 또는 dependsOn의 전이 선행 작업이 생산한 output이어야 합니다. 동일 이름을 여러 작업이 생산하면 모호하므로 거절합니다. 순서는 원래 task 배열에서 가능한 작업을 먼저 선택하므로 재현 가능합니다. 실행 시의 예산·취소·승인은 Studio Runner 또는 호스트의 별도 책임입니다.

## 입력 예의 사용

example-input.json은 가상 한빛팀 상황을 위해 새로 작성한 자료입니다. 예제 값은 실제 사용자 결과가 아닙니다. 실제 자료로 바꿀 때 원문 ID·버전·허용 범위를 보존하세요. 필수 입력을 제거하거나 근거를 바꾸면 성공 결과를 그대로 유지하지 말고 실패·미확인 처리를 적용합니다.
