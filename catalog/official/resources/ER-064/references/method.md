# API 변경 Skill: 판단·처리 기준

JSON Pointer에서 ~는 ~0, /는 ~1로 인코딩됩니다. 경로 객체의 parameters는 HTTP 작업으로 세지 않습니다. 배열은 순서를 가진 값으로 비교합니다. helper는 동등한 객체 키 순서를 무시하지만 참조 해석·코드 생성·네트워크 호출을 하지 않습니다.

## 입력 예의 사용

example-input.json은 가상 한빛팀 상황을 위해 새로 작성한 자료입니다. 예제 값은 실제 사용자 결과가 아닙니다. 실제 자료로 바꿀 때 원문 ID·버전·허용 범위를 보존하세요. 필수 입력을 제거하거나 근거를 바꾸면 성공 결과를 그대로 유지하지 말고 실패·미확인 처리를 적용합니다.
