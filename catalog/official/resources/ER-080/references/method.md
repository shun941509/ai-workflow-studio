# 재계획 비교 Skill: 판단·처리 기준

상태는 pending, completed, failed, outcome-unknown입니다. completed 단계는 정의와 resultSha256을 보존합니다. outcome-unknown은 외부 영향이 확인되지 않은 상태입니다. 프로그램은 ID 기반 차이를 검사하므로 이름만 바꾼 의미상 중복 작업은 검토자가 탐지해야 합니다.

## 입력 예의 사용

example-input.json은 가상 한빛팀 상황을 위해 새로 작성한 자료입니다. 예제 값은 실제 사용자 결과가 아닙니다. 실제 자료로 바꿀 때 원문 ID·버전·허용 범위를 보존하세요. 필수 입력을 제거하거나 근거를 바꾸면 성공 결과를 그대로 유지하지 말고 실패·미확인 처리를 적용합니다.
