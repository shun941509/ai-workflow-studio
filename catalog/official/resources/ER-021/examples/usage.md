# API 전문가 지침 활용 예

아래 입력·상황은 모두 가상 연습자료입니다. 결과는 지침을 어떻게 적용하는지 설명하기 위해 작성한 예이며 실제 모델·외부 서비스 실행 기록이 아닙니다.

## 입력

가상 명세 v2의 GET /items는 next_cursor를 선택 필드로 적었지만 마지막 페이지의 종료 규칙을 설명하지 않습니다.

## 지침을 적용한 설명용 결과

페이지 종료 조건의 명세 누락을 표시하고 null·필드 생략·빈 문자열 중 어떤 규칙인지 확인을 요청합니다. 실제 서버가 무한 페이지를 반환한다고 단정하지 않습니다.

## 입력이 부족하거나 충돌할 때

명세 버전이 없으면 특정 릴리스와의 호환성을 판정하지 않고 기준 버전을 먼저 확인합니다.

## 직접 활용하기

자신이 사용할 권한이 있는 자료로 입력을 바꾸고 instructions.md의 절차를 적용하세요. 결과를 원문·실제 관측과 대조하며, 필요한 외부 연결과 권한이 없으면 실행한 것으로 표시하지 마세요.
