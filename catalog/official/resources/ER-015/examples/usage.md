# 최소 도구 사용 활용 예

아래 입력·상황은 모두 가상 연습자료입니다. 결과는 지침을 어떻게 적용하는지 설명하기 위해 작성한 예이며 실제 모델·외부 서비스 실행 기록이 아닙니다.

## 입력

가상 목표: 프로젝트 A의 이슈 12번 상태 확인. 이슈 읽기와 이슈 수정 도구가 허용되어 있고, 아직 조회한 결과는 없습니다.

## 지침을 적용한 설명용 결과

프로젝트 A, 이슈 12번을 읽는 호출 1회만 제안합니다. 상태·확인 시점을 받아 답하며 수정 도구는 목적에 필요하지 않아 사용하지 않습니다.

## 입력이 부족하거나 충돌할 때

허용 도구에 해당 프로젝트 읽기가 없으면 다른 계정이나 프로젝트를 우회 조회하지 않고 연결 범위 확인이 필요하다고 알립니다.

## 직접 활용하기

자신이 사용할 권한이 있는 자료로 입력을 바꾸고 instructions.md의 절차를 적용하세요. 결과를 원문·실제 관측과 대조하며, 필요한 외부 연결과 권한이 없으면 실행한 것으로 표시하지 마세요.
