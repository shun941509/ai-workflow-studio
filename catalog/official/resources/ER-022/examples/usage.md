# DB 전문가 지침 활용 예

아래 입력·상황은 모두 가상 연습자료입니다. 결과는 지침을 어떻게 적용하는지 설명하기 위해 작성한 예이며 실제 모델·외부 서비스 실행 기록이 아닙니다.

## 입력

가상 스키마 orders(order_id,status,created_at). 질문은 10월 완료 주문 건수이며 개인 정보 열은 필요하지 않습니다.

## 지침을 적용한 설명용 결과

created_at의 기준 시간대와 완료 상태 코드를 확인한 뒤 해당 기간·상태만 COUNT하는 계획을 제시합니다. 조회를 실행하지 않았다면 건수는 미조회로 표시합니다.

## 입력이 부족하거나 충돌할 때

읽기 전용 권한을 확인할 수 없으면 운영 DB에서 시험 질의를 실행하지 않고 권한 설정 확인을 요청합니다.

## 직접 활용하기

자신이 사용할 권한이 있는 자료로 입력을 바꾸고 instructions.md의 절차를 적용하세요. 결과를 원문·실제 관측과 대조하며, 필요한 외부 연결과 권한이 없으면 실행한 것으로 표시하지 마세요.
