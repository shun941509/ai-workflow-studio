# DB 전문가 지침

읽기 중심 조사.

## 사용하는 방법

1. 이 폴더의 instructions.md를 AI 작업의 지침 또는 참고 파일로 연결합니다.
2. 필수 입력을 함께 제공하고, templates/result.md의 항목에 맞춰 결과를 요청합니다.
3. 결과를 원문·실제 관측과 대조합니다. 필요한 자료나 권한이 없으면 확인 필요 상태로 남깁니다.

입력과 결과: 질문·스키마 → 조회 계획

연결 설계: agent·tool / 제한 DB. 해당 블록과 도구가 준비된 환경에서 사용합니다. 이 지침 파일을 읽는 것만으로 도구·MCP·코드가 실행되지 않습니다.

## 준비 조건과 한계

- 실제 모델 프로필 연결·호출·사용량을 검증해야 합니다.
- 쓰기 금지된 실제 데이터베이스 권한과 조회 결과를 검증해야 합니다.

AI 도구를 이용할 경우 실제 모델 연결은 사용자가 준비합니다. 이 자료는 호스트에서의 실제 사용 성공이나 공식 검수·게시를 보증하지 않습니다.

## 구성

- instructions.md: 구체적인 작업 절차와 실패 처리
- templates/result.md: 출력 계약에 맞춘 빈 틀
- examples/usage.md: 가상 입력에 적용한 설명용 예
- LICENSE.md: 이 원본 자료의 사용·수정·재배포 조건
- resource.json: 고정 버전과 원본 파일 검증 값

## 결과 확인 기준

쓰기 제안 없이 필요한 범위만. 예시의 값을 그대로 사용하지 말고 자신의 입력과 실제 결과를 대조하세요.
