# 재시도 판단 활용 예

아래 입력·상황은 모두 가상 연습자료입니다. 결과는 지침을 어떻게 적용하는지 설명하기 위해 작성한 예이며 실제 모델·외부 서비스 실행 기록이 아닙니다.

## 입력

가상 사건: 외부 문서 생성 요청 W-19가 응답 시간 초과로 끝났습니다. 서버에서 실제로 처리되었는지는 아직 확인하지 못했습니다.

## 지침을 적용한 설명용 결과

상태는 결과 불명입니다. W-19 또는 멱등 키로 생성 결과를 조회합니다. 조회 수단이 없다면 대상 폴더를 담당자가 확인할 때까지 새 생성 요청을 보류합니다.

## 입력이 부족하거나 충돌할 때

요청 ID가 기록되지 않았으면 자동 재전송 대신 시각·대상·내용 요약으로 외부 상태를 확인할 사람을 지정하도록 요청합니다.

## 직접 활용하기

자신이 사용할 권한이 있는 자료로 입력을 바꾸고 instructions.md의 절차를 적용하세요. 결과를 원문·실제 관측과 대조하며, 필요한 외부 연결과 권한이 없으면 실행한 것으로 표시하지 마세요.
