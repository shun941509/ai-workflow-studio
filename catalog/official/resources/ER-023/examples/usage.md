# 성능 분석 지침 활용 예

아래 입력·상황은 모두 가상 연습자료입니다. 결과는 지침을 어떻게 적용하는지 설명하기 위해 작성한 예이며 실제 모델·외부 서비스 실행 기록이 아닙니다.

## 입력

가상 p95 지연이 동일 조건에서 200ms에서 250ms로 변했습니다. 표본은 각 1,000회입니다.

## 지침을 적용한 설명용 결과

관측 변화는 +50ms, +25%입니다. 원인은 아직 미확인입니다. 구간별 처리 시간과 오류율을 다음 측정으로 제안하고, 목표값이 없으므로 목표 충족 여부는 미판정으로 둡니다.

## 입력이 부족하거나 충돌할 때

현재 측정만 캐시를 비운 조건이면 조건 차이를 먼저 보고하고 동등 조건 재측정을 제안합니다.

## 직접 활용하기

자신이 사용할 권한이 있는 자료로 입력을 바꾸고 instructions.md의 절차를 적용하세요. 결과를 원문·실제 관측과 대조하며, 필요한 외부 연결과 권한이 없으면 실행한 것으로 표시하지 마세요.
