# 접근성 점검 Skill: 판단·처리 기준

references/screen.html은 로컬에서 열 수 있는 가상 신청 화면입니다. 버튼에 읽을 수 있는 이름이 있고 라벨과 오류가 연결되어 있는지 직접 관찰하세요. label 연결이나 색 대비의 한 가지 검사만으로 접근성 전체를 인증하지 않습니다. 자동 검사는 보조 수단입니다.

## 입력 예의 사용

example-input.json은 가상 한빛팀 상황을 위해 새로 작성한 자료입니다. 예제 값은 실제 사용자 결과가 아닙니다. 실제 자료로 바꿀 때 원문 ID·버전·허용 범위를 보존하세요. 필수 입력을 제거하거나 근거를 바꾸면 성공 결과를 그대로 유지하지 말고 실패·미확인 처리를 적용합니다.
