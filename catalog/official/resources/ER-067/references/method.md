# 성능 해석 Skill: 판단·처리 기준

평균=sum/n, 중앙값은 짝수개일 때 가운데 두 값의 평균, p95는 최근접 순위 정의를 사용합니다. 상대 변화=(after-before)/before*100이며 지연에서는 음수가 감소입니다. 측정 중 실패 요청이 제외됐는지 명시하고 실패율은 별도 지표로 보존합니다.

## 입력 예의 사용

example-input.json은 가상 한빛팀 상황을 위해 새로 작성한 자료입니다. 예제 값은 실제 사용자 결과가 아닙니다. 실제 자료로 바꿀 때 원문 ID·버전·허용 범위를 보존하세요. 필수 입력을 제거하거나 근거를 바꾸면 성공 결과를 그대로 유지하지 말고 실패·미확인 처리를 적용합니다.
