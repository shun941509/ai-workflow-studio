# 기능 카탈로그

문서 ID: ER-047 / 버전 1.0 / 기준일 2026-10-01

이 문서와 데이터의 기관 “한빛 업무연구소”, 제품 “라온 협업보드”, 역할·업무·기록은 모두 가상입니다. 실제 고객·개인·제3자 문서를 사용하지 않았습니다. 예시를 실제 서비스 정책이나 사건으로 오인하지 마세요.

## CAT-01 비교 대상
가상 제품 라온 협업보드의 Basic·Team을 비교합니다. 모든 기능은 고유 ID가 있고 숫자·불리언을 구분합니다. false를 값 누락으로 해석하지 않습니다.

| 기능 ID | 기능 | Basic | Team | 단위·제약 |
|---|---|---|---|---|
| F-001 | 구성원 한도 | 5 | 25 | members / 워크스페이스당 |
| F-002 | 파일 크기 | 20 | 100 | MiB / 파일 하나당 |
| F-003 | 휴지통 보관 | 30 | 90 | days / 삭제 시점부터 |
| F-004 | CSV 내보내기 | true | true |  / 읽기 권한 필드만 |
| F-005 | API 조회 | false | true |  / reports:read와 프로젝트 권한 필요 |
| F-006 | 프로젝트 기본 공개 | false | false |  / 명시적 공개 승인 필요 |
| F-007 | 초대 유효 시간 | 48 | 48 | hours / 일회용 링크 |
| F-008 | UTC 저장 | true | true |  / 표시 시간대는 사용자 선택 |
| F-009 | 필드별 접근 제한 | false | true |  / 권한 밖 필드는 검색·CSV에서 제외 |
| F-010 | 감사 기록 보관 | 7 | 90 | days / 조회 권한 별도 |
| F-011 | 동시 보고서 생성 | 1 | 3 | jobs / 상한 초과는 대기 |
| F-012 | 사용자 정의 역할 | false | true |  / 범위 담당자만 관리 |

## CAT-02 적용 예
구성원 8명과 API 조회가 필요하면 F-001·F-005를 모두 만족하는 플랜을 찾습니다. Basic은 두 기준을 충족하지 못하고 Team은 충족합니다. 가격 정보가 없으므로 비용 대비 추천은 할 수 없습니다.

## CAT-03 검토 기준
features.json의 ID·자료형·단위·제약을 유지해 비교표를 만드세요. 조건 하나만 보고 나머지를 생략하지 말고, 자료에 없는 기능은 미확인으로 남깁니다.
