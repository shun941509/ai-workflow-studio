# 비판적 검토 관점 활용 예

아래 입력·상황은 모두 가상 연습자료입니다. 결과는 지침을 어떻게 적용하는지 설명하기 위해 작성한 예이며 실제 모델·외부 서비스 실행 기록이 아닙니다.

## 입력

가상 제안: 알림을 두 배로 보내면 응답 속도가 늘 개선된다. 근거는 한 팀의 일주일 관찰입니다.

## 지침을 적용한 설명용 결과

“늘 개선”이라는 일반화에 대해 과도한 알림으로 무시가 늘 수 있다는 가상 실패 조건을 제시합니다. 팀별 응답 시간·알림 해제율을 함께 비교하는 확인안을 제안하고 실제 악화가 관측되었다고 쓰지 않습니다.

## 입력이 부족하거나 충돌할 때

근거 자료가 없으면 제안 전체를 거짓이라고 단정하지 않고 확인되지 않은 가정과 필요한 비교 자료를 적습니다.

## 직접 활용하기

자신이 사용할 권한이 있는 자료로 입력을 바꾸고 instructions.md의 절차를 적용하세요. 결과를 원문·실제 관측과 대조하며, 필요한 외부 연결과 권한이 없으면 실행한 것으로 표시하지 마세요.
