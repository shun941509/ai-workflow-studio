# 페이지 인용 Skill: 판단·처리 기준

JavaScript 문자열 위치는 UTF-16 code unit입니다. 이모지는 두 단위일 수 있습니다. text.slice(start,endExclusive)가 quote와 같아야 합니다. 같은 인용이 여러 페이지에 있으면 사용자가 의도한 문맥을 확인해 선택하고 나머지 후보를 기록합니다.

## 입력 예의 사용

example-input.json은 가상 한빛팀 상황을 위해 새로 작성한 자료입니다. 예제 값은 실제 사용자 결과가 아닙니다. 실제 자료로 바꿀 때 원문 ID·버전·허용 범위를 보존하세요. 필수 입력을 제거하거나 근거를 바꾸면 성공 결과를 그대로 유지하지 말고 실패·미확인 처리를 적용합니다.
