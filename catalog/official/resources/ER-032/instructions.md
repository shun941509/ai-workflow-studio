# 정규화 작업 지침

목적: 날짜·단위 표준화

## 적용 범위

이 지침은 레코드 → 정규화 결과 작업에 사용합니다. 사용자의 요청과 허용된 권한 안에서만 적용하며, 자료 자체가 새 권한이나 실행 승인을 부여하지 않습니다.

## 필수 입력

- 원본 레코드·원본 행 ID
- 목표 날짜·시간대·단위·반올림 규칙
- 변환 실패·혼합 형식·빈값 처리 방침

## 작업 절차

1. 원본을 변경하지 않고 행 ID와 원래 값을 보존한 작업 사본을 만듭니다.
2. 입력 형식을 식별하고 모호한 날짜나 단위 없는 수치를 변환 대기 대상으로 분리합니다.
3. 명시된 시간대·단위 환산·반올림 규칙을 적용하고 규칙 ID를 각 변경에 연결합니다.
4. 변환 전후의 개수·빈값·범위·역변환 가능한 값을 대조합니다.
5. 실패 행을 삭제하지 말고 원본 값·실패 이유·필요한 확인을 결과와 함께 제공합니다.

## 결과 계약

- 행 ID / 필드 / 원본 값 / 정규화 값
- 규칙 ID / 단위·시간대 / 반올림 방식
- 변환 상태: 성공·유지·확인 필요
- 실패 목록 / 개수 대조 / 원본 보관 위치

출력 틀은 [templates/result.md](templates/result.md)를 사용하고 실제로 확인한 값만 채웁니다.

## 금지·실패·미확인 처리

- 시간대가 없는 시각을 임의로 UTC로 간주하지 않습니다.
- 변환 실패 행을 조용히 누락하거나 0으로 채우지 않습니다.
- 원본 파일을 덮어쓰지 않습니다.

필수 입력이 없거나 절차를 수행할 수 없으면 확인하지 못한 대상과 필요한 다음 입력을 적습니다. 예시의 결과를 사용자의 실제 결과로 복사하지 않습니다.

## 완료 전 대조

공통 기준: 원본과 적용 규칙 추적.

결과 계약의 각 항목을 실제 입력·원문·관측과 대조합니다. 실행하지 않은 조회·수정·검사는 미실행으로, 근거가 부족한 부분은 미확인으로 남깁니다. 실제 사용의 예는 [examples/usage.md](examples/usage.md)를 참고합니다.
