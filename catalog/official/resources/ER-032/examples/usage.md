# 정규화 작업 지침 활용 예

아래 입력·상황은 모두 가상 연습자료입니다. 결과는 지침을 어떻게 적용하는지 설명하기 위해 작성한 예이며 실제 모델·외부 서비스 실행 기록이 아닙니다.

## 입력

가상 규칙 U1은 cm를 m로 바꾸고 소수 둘째 자리까지 표시합니다. 행 A의 값은 125 cm, 행 B는 단위 없는 80입니다.

## 지침을 적용한 설명용 결과

A는 1.25 m, 규칙 U1 적용으로 기록합니다. B는 원본 80을 유지하고 단위 확인 필요로 분리합니다. 입력 2행과 결과·확인 대상 합계 2행을 대조합니다.

## 입력이 부족하거나 충돌할 때

03/04/2026의 날짜 순서 규칙이 없으면 날짜 변환을 보류하고 원문 값을 보존합니다.

## 직접 활용하기

자신이 사용할 권한이 있는 자료로 입력을 바꾸고 instructions.md의 절차를 적용하세요. 결과를 원문·실제 관측과 대조하며, 필요한 외부 연결과 권한이 없으면 실행한 것으로 표시하지 마세요.
