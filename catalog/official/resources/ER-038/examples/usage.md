# 재계획 지침 활용 예

아래 입력·상황은 모두 가상 연습자료입니다. 결과는 지침을 어떻게 적용하는지 설명하기 위해 작성한 예이며 실제 모델·외부 서비스 실행 기록이 아닙니다.

## 입력

가상 계획은 문서 읽기→표 추출→보고서 작성입니다. 읽기는 완료했고 표 추출이 지원하지 않는 형식으로 실패했습니다.

## 지침을 적용한 설명용 결과

읽은 문서와 버전을 보존합니다. 사용자가 변환한 지원 형식을 제공하는 경로를 제안하고 그 전까지 표 추출·보고서 수치를 대기로 둡니다. 새 외부 변환 서비스 업로드는 자동으로 추가하지 않습니다.

## 입력이 부족하거나 충돌할 때

외부 업로드가 시간 초과로 끝났다면 먼저 업로드 상태를 확인하고 다른 서비스로 동일 파일을 재전송하지 않습니다.

## 직접 활용하기

자신이 사용할 권한이 있는 자료로 입력을 바꾸고 instructions.md의 절차를 적용하세요. 결과를 원문·실제 관측과 대조하며, 필요한 외부 연결과 권한이 없으면 실행한 것으로 표시하지 마세요.
