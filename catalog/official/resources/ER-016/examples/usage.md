# 변경 작업 설명 활용 예

아래 입력·상황은 모두 가상 연습자료입니다. 결과는 지침을 어떻게 적용하는지 설명하기 위해 작성한 예이며 실제 모델·외부 서비스 실행 기록이 아닙니다.

## 입력

가상 변경 제안: 이슈 I-27의 제목을 “문의”에서 “로그인 오류 재현 정보 요청”으로 바꾸고 다른 필드는 유지합니다.

## 지침을 적용한 설명용 결과

승인 대상은 I-27의 제목 수정 1건입니다. 전후 제목을 나란히 보여 주고 댓글 작성·담당자 변경은 포함하지 않는다고 표시합니다. 아직 실행하지 않았으며 실행 시 다른 제목으로 바뀌면 재확인이 필요합니다.

## 입력이 부족하거나 충돌할 때

실제 이슈 ID가 없으면 이름만으로 변경을 승인받지 않고 대상 식별부터 요청합니다.

## 직접 활용하기

자신이 사용할 권한이 있는 자료로 입력을 바꾸고 instructions.md의 절차를 적용하세요. 결과를 원문·실제 관측과 대조하며, 필요한 외부 연결과 권한이 없으면 실행한 것으로 표시하지 마세요.
