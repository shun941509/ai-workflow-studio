# RAG 답변 유보 활용 예

아래 입력·상황은 모두 가상 연습자료입니다. 결과는 지침을 어떻게 적용하는지 설명하기 위해 작성한 예이며 실제 모델·외부 서비스 실행 기록이 아닙니다.

## 입력

가상 질문은 제품 Q의 환불 기간입니다. 후보는 배송 기간 3일을 설명하고 환불에 관한 내용은 없습니다.

## 지침을 적용한 설명용 결과

환불 기간은 제공 근거로 확인할 수 없어 유보합니다. 배송 3일을 환불 3일로 바꾸지 않습니다. 환불 정책 문서 또는 해당 조항이 필요하다고 안내합니다.

## 입력이 부족하거나 충돌할 때

환불 정책 두 버전의 기간이 충돌하면 적용 버전 확인 전 확정하지 않고 양쪽 출처와 시점을 제시합니다.

## 직접 활용하기

자신이 사용할 권한이 있는 자료로 입력을 바꾸고 instructions.md의 절차를 적용하세요. 결과를 원문·실제 관측과 대조하며, 필요한 외부 연결과 권한이 없으면 실행한 것으로 표시하지 마세요.
