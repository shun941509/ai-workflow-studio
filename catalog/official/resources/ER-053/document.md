# 역할·담당 범위표

문서 ID: ER-053 / 버전 1.0 / 기준일 2026-10-01

이 문서와 데이터의 기관 “한빛 업무연구소”, 제품 “라온 협업보드”, 역할·업무·기록은 모두 가상입니다. 실제 고객·개인·제3자 문서를 사용하지 않았습니다. 예시를 실제 서비스 정책이나 사건으로 오인하지 마세요.

## ROLE-01 범위표
아래는 가상 조직의 역할이며 실제 개인을 지정하지 않습니다. 역할별 허용 행동은 작업별 권한을 추가로 좁힐 수 있고 역할 이름만으로 새 권한이 생기지 않습니다.

## R-PLAN 기획 역할
책임: 범위 결정·우선순위·공개 요청 검토.

허용: 요구사항 읽기·계획 초안·범위 승인.

제외: 운영 설정 직접 변경·비밀 값 조회.

## R-OPS 운영 역할
책임: 운영 상태 확인·접근 범위 점검·사건 인계.

허용: 허용 로그 읽기·승인된 상태 조회.

제외: 승인 없는 재시작·다른 조직 로그 조회.

## R-QA 검토 역할
책임: 결과 기준 검사·근거 대조.

허용: 제공 원문 읽기·검사 결과 작성.

제외: 검사 없이 통과 표시·외부 발행.

## R-EDITOR 편집 역할
책임: 초안 작성·문구 정리·통합 문서.

허용: 제공 자료 편집 사본 작성.

제외: 원본 덮어쓰기·공개 승인 대행.

## ROLE-02 배정 사례
보고서 초안은 R-EDITOR, 결과 검사는 R-QA, 공개 범위 결정은 R-PLAN, 실제 접근 범위 확인은 R-OPS에 연결합니다. 법률 판단·결제 승인·인사 평가는 이 표에 책임 역할이 없으므로 담당 미정으로 남깁니다.

## ROLE-03 인계
각 작업에 최종 책임 역할 한 개를 기록하고 협업 역할은 따로 적습니다. 권한이 없는 업무를 처리하기 위해 존재하지 않는 역할이나 담당자를 만들지 않습니다.
