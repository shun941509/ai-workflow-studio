# 실제 외부 연결 계약

공식 API 근거: https://developers.openai.com/api/reference/resources/embeddings/methods/create (계약 확인 2026-10-28). 공급자 계정과 이용 가능한 모델은 사용자가 따로 준비합니다. 실제 공급자 실행·계정·키 생성은 이 자료 제작 과정에서 하지 않았습니다.

prepare는 전송하지 않습니다. execute+send=true는 문서를 외부 서비스에 보내는 명시적 선택입니다. 필요한 환경 변수는 SKILL.md에 있으며 호스트 비밀정보 관리 기능으로만 주입하세요. 키를 자료 파일·JSON·명령 인수·로그에 저장하지 마세요.

고정 HTTPS 주소, 운영체제 신뢰 저장소의 TLS 검증, 20초 소켓 제한, 8MiB 응답 제한을 사용합니다. 프록시·리다이렉트·자동 재시도는 허용하지 않습니다. 전체 실행 시간·OS 격리·취소는 호스트가 제어해야 합니다. 전송 후 오류에서는 과금 여부가 미확정일 수 있으므로 무조건 재전송하지 마세요.

응답의 계약 일치는 모델 품질·불변 가중치·게시 승인 증거가 아닙니다. 실제 입력·프로필·응답·권한·비용을 검토한 뒤 사용 기록을 별도로 남기세요.
