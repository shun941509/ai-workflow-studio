# 목표 명세 Skill: 판단·처리 기준

목표는 바꾸려는 상태, 산출물은 전달할 물건입니다. “주간 현황 파악”은 목표이고 “팀 회의용 한 페이지 표”는 산출물입니다. acceptance는 대상·검사법·기대값을 포함합니다. 달력 날짜가 필요한데 “다음 주”만 있으면 기준 날짜와 시간대를 확인합니다.

## 입력 예의 사용

example-input.json은 가상 한빛팀 상황을 위해 새로 작성한 자료입니다. 예제 값은 실제 사용자 결과가 아닙니다. 실제 자료로 바꿀 때 원문 ID·버전·허용 범위를 보존하세요. 필수 입력을 제거하거나 근거를 바꾸면 성공 결과를 그대로 유지하지 말고 실패·미확인 처리를 적용합니다.
