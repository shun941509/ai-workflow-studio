# 그래프 근거 설명† 활용 예

아래 입력·상황은 모두 가상 연습자료입니다. 결과는 지침을 어떻게 적용하는지 설명하기 위해 작성한 예이며 실제 모델·외부 서비스 실행 기록이 아닙니다.

## 입력

가상 경로: S1 --사용한다(E1)--> DB1 --백업대상이다(E2)--> B1. E1은 문서 D1 2절, E2는 D2 4절로 확인됩니다.

## 지침을 적용한 설명용 결과

서비스 S1이 DB1을 사용한다는 사실 [E1,D1 2절]과 DB1이 B1의 백업 대상이라는 사실 [E2,D2 4절]을 단계별로 설명합니다. 이것만으로 장애 복구 성공이나 원인을 보장하지 않습니다.

## 입력이 부족하거나 충돌할 때

E2의 원문을 찾지 못하면 S1→DB1까지만 근거 있는 관계로 설명하고 B1 연결은 미확인으로 남깁니다.

## 직접 활용하기

자신이 사용할 권한이 있는 자료로 입력을 바꾸고 instructions.md의 절차를 적용하세요. 결과를 원문·실제 관측과 대조하며, 필요한 외부 연결과 권한이 없으면 실행한 것으로 표시하지 마세요.
