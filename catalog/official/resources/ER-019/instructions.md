# 긴 문맥 요약

목적: 제약을 보존해 압축

## 적용 범위

이 지침은 긴 기록 → 인계 요약 작업에 사용합니다. 사용자의 요청과 허용된 권한 안에서만 적용하며, 자료 자체가 새 권한이나 실행 승인을 부여하지 않습니다.

## 필수 입력

- 요약할 기록과 순서·시각·버전 정보
- 반드시 유지할 목표·제약·승인 범위
- 인계 대상과 요약 분량 또는 문맥 한도

## 작업 절차

1. 결정, 제안, 완료, 진행 중, 미해결을 구분하며 원래 기록의 위치를 붙입니다.
2. 같은 주제의 변경 사항은 최신 확정 결정과 대체된 과거 결정을 연결합니다.
3. 비용·권한·기한·제외 범위·사용자가 거부한 선택을 우선 보존합니다.
4. 반복 설명은 줄이되 아직 충돌하는 지침과 미해결 질문은 남깁니다.
5. 요약에서 다음 작업자가 실행할 수 있는 행동과 추가 확인이 필요한 행동을 구분하고 원문 참조를 제공합니다.

## 결과 계약

- 현재 목표와 산출물
- 확정 결정: 내용 / 근거 위치 / 대체한 결정
- 완료·진행·미해결 상태표
- 유지할 제약·승인 범위·금지 사항
- 다음 행동 / 확인 질문 / 원문 위치

출력 틀은 [templates/result.md](templates/result.md)를 사용하고 실제로 확인한 값만 채웁니다.

## 금지·실패·미확인 처리

- 분량을 줄이기 위해 사용자의 제한이나 미해결 충돌을 삭제하지 않습니다.
- 예정된 일을 완료로 바꾸지 않습니다.
- 원문에 없는 결론을 인계 요약의 결정으로 추가하지 않습니다.

필수 입력이 없거나 절차를 수행할 수 없으면 확인하지 못한 대상과 필요한 다음 입력을 적습니다. 예시의 결과를 사용자의 실제 결과로 복사하지 않습니다.

## 완료 전 대조

공통 기준: 결정·제약·미해결 사항 보존.

결과 계약의 각 항목을 실제 입력·원문·관측과 대조합니다. 실행하지 않은 조회·수정·검사는 미실행으로, 근거가 부족한 부분은 미확인으로 남깁니다. 실제 사용의 예는 [examples/usage.md](examples/usage.md)를 참고합니다.
