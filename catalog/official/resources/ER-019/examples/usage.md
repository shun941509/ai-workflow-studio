# 긴 문맥 요약 활용 예

아래 입력·상황은 모두 가상 연습자료입니다. 결과는 지침을 어떻게 적용하는지 설명하기 위해 작성한 예이며 실제 모델·외부 서비스 실행 기록이 아닙니다.

## 입력

가상 기록: 1번에서 외부 발송을 검토했지만, 8번에서 사용자가 “오늘은 초안만 작성”이라고 확정했습니다. 초안은 아직 작성 중입니다.

## 지침을 적용한 설명용 결과

현재 범위는 초안 작성이며 외부 발송은 제외합니다 [8번]. 발송 검토는 대체된 제안 [1번]으로 남깁니다. 상태는 작성 중이고 다음 행동은 초안을 완성해 사용자 검토에 올리는 것입니다.

## 입력이 부족하거나 충돌할 때

결정 시점이 뒤섞여 최신 여부를 판단할 수 없으면 두 지시를 충돌로 남기고 우선순위를 확인합니다.

## 직접 활용하기

자신이 사용할 권한이 있는 자료로 입력을 바꾸고 instructions.md의 절차를 적용하세요. 결과를 원문·실제 관측과 대조하며, 필요한 외부 연결과 권한이 없으면 실행한 것으로 표시하지 마세요.
