# 회의 후속 Skill: 판단·처리 기준

references/meeting.md의 가상 회의에는 확정 업무 1개와 제안 1개, 담당 미정 업무 1개가 있습니다. 발언 번호가 근거 위치입니다. 정리 결과에서 작업 상태는 기본 “미착수/상태 미확인”으로 두며 회의 중 이미 완료됐다는 근거가 있을 때만 완료로 씁니다.

## 입력 예의 사용

example-input.json은 가상 한빛팀 상황을 위해 새로 작성한 자료입니다. 예제 값은 실제 사용자 결과가 아닙니다. 실제 자료로 바꿀 때 원문 ID·버전·허용 범위를 보존하세요. 필수 입력을 제거하거나 근거를 바꾸면 성공 결과를 그대로 유지하지 말고 실패·미확인 처리를 적용합니다.
