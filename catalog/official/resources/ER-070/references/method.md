# 관점별 이견 Skill: 판단·처리 기준

관점 카드는 관심 범위를 정하는 분석 도구입니다. 기술: 실패 복구와 계약. 운영: 반복 수작업과 지원 부담. 사용자: 시작 가능성·혼동·실수 회복. 주장에는 observed, inferred, unknown을 붙이고 하나의 출처를 공유하면 그 의존을 표시합니다.

## 입력 예의 사용

example-input.json은 가상 한빛팀 상황을 위해 새로 작성한 자료입니다. 예제 값은 실제 사용자 결과가 아닙니다. 실제 자료로 바꿀 때 원문 ID·버전·허용 범위를 보존하세요. 필수 입력을 제거하거나 근거를 바꾸면 성공 결과를 그대로 유지하지 말고 실패·미확인 처리를 적용합니다.
