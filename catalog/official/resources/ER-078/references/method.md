# Sub Agent 인계 Skill: 판단·처리 기준

완료 조건은 관측할 대상·기대값·근거 위치를 포함합니다. 출력 필드는 이름만 아니라 타입·null 허용을 고정합니다. 하위가 이미 실행한 외부 변경의 상태가 불명이면 자동 재위임을 금지하고 상태 확인을 우선합니다. Schema의 구조 검사는 실제 파일 해시 검사나 권한 부여를 대체하지 않습니다.

## 입력 예의 사용

example-input.json은 가상 한빛팀 상황을 위해 새로 작성한 자료입니다. 예제 값은 실제 사용자 결과가 아닙니다. 실제 자료로 바꿀 때 원문 ID·버전·허용 범위를 보존하세요. 필수 입력을 제거하거나 근거를 바꾸면 성공 결과를 그대로 유지하지 말고 실패·미확인 처리를 적용합니다.
