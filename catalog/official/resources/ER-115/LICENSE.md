# Studio 원본 예제자료 이용 조건 v1

scripts/vendor/의 제3자 코드를 제외한 이 폴더의 Skill 지침·자체 코드·스키마·설명·템플릿·가상 문서와 데이터는 AI Workflow Studio 예제를 위해 새로 작성한 원본 자료입니다.

이 원본 자료에 관하여 적법하게 허용할 수 있는 범위에서, 개인·교육·업무·상업적 목적의 사용, 복제, 수정, 결합 및 재배포를 허용합니다. 재배포할 때에는 이 이용 조건과 “AI Workflow Studio 원본 예제자료”라는 출처 표시를 포함하고, 수정한 부분이 있으면 수정 사실을 밝혀 주세요.

이 허용은 외부 문서, 서비스, 상표, 고객 데이터 등 제3자의 자료나 권리를 포함하지 않습니다. 별도로 추가한 자료에는 해당 자료의 권한과 이용 조건을 확인해야 합니다. 특정 전문가 자격·공식 인증·실제 실행 성공을 나타내는 표시로 사용할 수 없습니다.

자료는 일반적인 작업 보조용으로 제공하며 정확성·목적 적합성·서비스 연결 또는 실행 결과를 보장하지 않습니다. 사용자는 실제 입력과 환경에 맞게 검토하고 권한·개인정보·공개 범위를 확인해야 합니다.

연습용 이름·상황·기록은 가상이며 실제 고객·개인에 관한 정보가 아닙니다.

## 포함된 제3자 코드

scripts/vendor/tokenizer.mjs는 js-tiktoken 1.0.21 및 base64-js 1.5.1을 고정 번들한 파일입니다. 각 원본 MIT 저작권·허가문을 같은 폴더의 LICENSE 파일에 보존했습니다. 해당 부분은 각 원본 조건을 따르며 이 Studio 이용 조건으로 추가 권리를 부여하지 않습니다. provenance.json에 원본과 번들 해시를 기록했습니다.
