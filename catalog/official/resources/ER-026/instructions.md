# 초보 사용자 관점

목적: 안내 이해도 점검

## 적용 범위

이 지침은 설명 → 혼동·누락 작업에 사용합니다. 사용자의 요청과 허용된 권한 안에서만 적용하며, 자료 자체가 새 권한이나 실행 승인을 부여하지 않습니다.

## 필수 입력

- 검토할 안내문과 시작 화면·작업 목표
- 가정할 초보 사용자의 배경지식
- 실제 제공되는 버튼·입력·오류 안내

## 작업 절차

1. 사용자가 첫 행동을 찾을 수 있는지 안내문의 순서대로 따라갑니다.
2. 처음 등장하는 전문 용어, 모호한 지시어, 생략된 선행 조건을 문장 위치와 함께 표시합니다.
3. 각 단계에 사용자가 할 행동과 그 뒤 보일 결과가 있는지 확인합니다.
4. 문제가 생겼을 때 돌아갈 위치나 다음 선택이 안내되어 있는지 확인합니다.
5. 관점 기반 검토와 실제 사용자 관찰을 구분하고, 작은 문구 수정과 구조 변경을 나눠 제안합니다.

## 결과 계약

- 원문 위치 / 이해하기 어려운 표현
- 필요한 배경지식 또는 빠진 단계
- 예상 혼동 / 수정 문구
- 다음 행동과 성공 확인 방법
- 실제 사용자 관찰 필요 항목

출력 틀은 [templates/result.md](templates/result.md)를 사용하고 실제로 확인한 값만 채웁니다.

## 금지·실패·미확인 처리

- 가상의 초보 사용자 반응을 실제 인터뷰나 사용성 조사 결과로 표현하지 않습니다.
- 제품에 없는 버튼이나 자동 기능을 수정 문구에 추가하지 않습니다.
- 어려운 용어를 빼면서 중요한 조건까지 지우지 않습니다.

필수 입력이 없거나 절차를 수행할 수 없으면 확인하지 못한 대상과 필요한 다음 입력을 적습니다. 예시의 결과를 사용자의 실제 결과로 복사하지 않습니다.

## 완료 전 대조

공통 기준: 용어·다음 행동을 구체 지적.

결과 계약의 각 항목을 실제 입력·원문·관측과 대조합니다. 실행하지 않은 조회·수정·검사는 미실행으로, 근거가 부족한 부분은 미확인으로 남깁니다. 실제 사용의 예는 [examples/usage.md](examples/usage.md)를 참고합니다.
