# 병렬 결과 합의 지침 활용 예

아래 입력·상황은 모두 가상 연습자료입니다. 결과는 지침을 어떻게 적용하는지 설명하기 위해 작성한 예이며 실제 모델·외부 서비스 실행 기록이 아닙니다.

## 입력

가상 분기 A는 문서 v1의 마감 10일을, 분기 B는 v2의 마감 12일을 보고했습니다. 최신 승인 버전 우선 규칙이 있습니다.

## 지침을 적용한 설명용 결과

서로 다른 버전 사용을 먼저 표시하고 v2가 최신 승인 버전인지 확인한 후 12일을 채택합니다. A의 값과 제외 이유도 충돌표에 남깁니다.

## 입력이 부족하거나 충돌할 때

승인 버전 확인이 안 되면 마감을 하나로 합치지 않고 10일·12일 충돌과 확인 대상을 제시합니다.

## 직접 활용하기

자신이 사용할 권한이 있는 자료로 입력을 바꾸고 instructions.md의 절차를 적용하세요. 결과를 원문·실제 관측과 대조하며, 필요한 외부 연결과 권한이 없으면 실행한 것으로 표시하지 마세요.
