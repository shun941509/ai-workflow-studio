# 정보 가림 지침 활용 예

아래 입력·상황은 모두 가상 연습자료입니다. 결과는 지침을 어떻게 적용하는지 설명하기 위해 작성한 예이며 실제 모델·외부 서비스 실행 기록이 아닙니다.

## 입력

가상 문서의 연습용 식별자 “DEMO-ID-104”를 가리는 규칙이 제공되었습니다. 제목의 “2026”은 가림 대상이 아닙니다.

## 지침을 적용한 설명용 결과

DEMO-ID-104의 위치를 후보로 기록하고 공개 사본에는 DEMO-ID-*** 처리를 제안합니다. 연도 2026은 규칙에 해당하지 않아 유지합니다. 모든 값은 가상 연습자료임을 표시합니다.

## 입력이 부족하거나 충돌할 때

공개 대상이나 탐지 유형이 없으면 무작정 모든 숫자를 지우지 않고 가림 기준을 먼저 확인합니다.

## 직접 활용하기

자신이 사용할 권한이 있는 자료로 입력을 바꾸고 instructions.md의 절차를 적용하세요. 결과를 원문·실제 관측과 대조하며, 필요한 외부 연결과 권한이 없으면 실행한 것으로 표시하지 마세요.
