# 정보 가림 지침

목적: 공개 전 검토

## 적용 범위

이 지침은 문서 → 가림 후보 작업에 사용합니다. 사용자의 요청과 허용된 권한 안에서만 적용하며, 자료 자체가 새 권한이나 실행 승인을 부여하지 않습니다.

## 필수 입력

- 공개하려는 문서와 공개 대상
- 가릴 정보 유형·예외·검토 기준
- 원본 보존 위치와 공개 사본의 허용 형식

## 작업 절차

1. 전화번호·식별자 등 사용자가 정의한 탐지 유형과 예외를 먼저 고정합니다.
2. 원본에서 후보 구간을 찾고 유형·위치·판단 이유를 기록합니다. 검토표 자체에도 민감 원문이 재노출되지 않게 부분 가림을 사용합니다.
3. 확실한 후보와 문맥 확인이 필요한 후보를 나눠 사용자 검토에 제시합니다.
4. 승인된 규칙으로 별도 공개 사본을 만들 계획을 작성하고 원본은 보존합니다.
5. 본문뿐 아니라 주석·속성·숨은 열·첨부 등 검토한 범위를 적고 처리 후 잔여 노출을 재확인합니다.

## 결과 계약

- 유형 / 문서 위치 / 가린 후보 표시
- 탐지 이유 / 확실·문맥 확인 필요
- 제안 처리 / 예외 근거 / 검토 상태
- 공개 사본 범위 / 원본 보존 / 재확인 항목

출력 틀은 [templates/result.md](templates/result.md)를 사용하고 실제로 확인한 값만 채웁니다.

## 금지·실패·미확인 처리

- 유형 목록에 없는 모든 민감 정보까지 제거했다고 보장하지 않습니다.
- 자동 탐지 후보를 사용자 검토 없이 삭제한 것으로 처리하지 않습니다.
- 원본 파일이나 검토 로그에 민감 값을 불필요하게 복제하지 않습니다.

필수 입력이 없거나 절차를 수행할 수 없으면 확인하지 못한 대상과 필요한 다음 입력을 적습니다. 예시의 결과를 사용자의 실제 결과로 복사하지 않습니다.

## 완료 전 대조

공통 기준: 정의한 유형 검출·검토.

결과 계약의 각 항목을 실제 입력·원문·관측과 대조합니다. 실행하지 않은 조회·수정·검사는 미실행으로, 근거가 부족한 부분은 미확인으로 남깁니다. 실제 사용의 예는 [examples/usage.md](examples/usage.md)를 참고합니다.
