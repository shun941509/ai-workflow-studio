# 빌드 오류 분석 활용 예

아래 입력·상황은 모두 가상 연습자료입니다. 결과는 지침을 어떻게 적용하는지 설명하기 위해 작성한 예이며 실제 모델·외부 서비스 실행 기록이 아닙니다.

## 입력

가상 로그의 첫 오류는 config.ts에서 필수 속성 region 누락입니다. 뒤이어 번들 생성 실패가 나옵니다.

## 지침을 적용한 설명용 결과

region 누락을 우선 확인 대상으로 삼고 config 타입과 실제 설정을 대조합니다. 번들 실패는 연쇄 결과일 수 있다고 표시하며 전체 패키지 교체를 첫 조치로 제안하지 않습니다.

## 입력이 부족하거나 충돌할 때

마지막 “build failed” 한 줄만 있으면 원인을 단정하지 않고 첫 오류와 실행 명령을 요청합니다.

## 직접 활용하기

자신이 사용할 권한이 있는 자료로 입력을 바꾸고 instructions.md의 절차를 적용하세요. 결과를 원문·실제 관측과 대조하며, 필요한 외부 연결과 권한이 없으면 실행한 것으로 표시하지 마세요.
