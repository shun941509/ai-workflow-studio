# 완료 조건 지침 활용 예

아래 입력·상황은 모두 가상 연습자료입니다. 결과는 지침을 어떻게 적용하는지 설명하기 위해 작성한 예이며 실제 모델·외부 서비스 실행 기록이 아닙니다.

## 입력

가상 작업: 주간 보고서에 완료 업무 3건과 다음 주 계획을 포함해야 합니다. 제공 문서에는 완료 업무 2건만 있습니다.

## 지침을 적용한 설명용 결과

완료 업무 항목은 보고서 “이번 주 결과” 절에서 건수를 세어 검사합니다. 기대값은 3건이고 관측값은 2건이므로 실패입니다. 다음 주 계획은 별도 행에서 존재 여부와 구체적 행동을 검사합니다.

## 입력이 부족하거나 충돌할 때

보고서 파일 자체가 없으면 두 기준을 미검증으로 표시하고 필요한 파일을 요청합니다. 요구사항에 적힌 3건을 실제 완료 건수로 복사하지 않습니다.

## 직접 활용하기

자신이 사용할 권한이 있는 자료로 입력을 바꾸고 instructions.md의 절차를 적용하세요. 결과를 원문·실제 관측과 대조하며, 필요한 외부 연결과 권한이 없으면 실행한 것으로 표시하지 마세요.
