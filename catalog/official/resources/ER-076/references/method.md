# 역할 분배 Skill: 판단·처리 기준

owner는 산출물 완료 책임을 뜻하고 contributor는 부분 지원입니다. 승인 권한은 별도 주체에 남깁니다. 부모가 read:provided-files만 허용했다면 write:external은 하위 계약에 들어갈 수 없습니다. JSON Schema는 구조를 검사하고 업무 전체 커버리지·권한 부분집합은 절차로 추가 검사합니다.

## 입력 예의 사용

example-input.json은 가상 한빛팀 상황을 위해 새로 작성한 자료입니다. 예제 값은 실제 사용자 결과가 아닙니다. 실제 자료로 바꿀 때 원문 ID·버전·허용 범위를 보존하세요. 필수 입력을 제거하거나 근거를 바꾸면 성공 결과를 그대로 유지하지 말고 실패·미확인 처리를 적용합니다.
