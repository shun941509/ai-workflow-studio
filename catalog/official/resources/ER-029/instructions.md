# 쉬운 설명 편집

목적: 전문 표현 변환

## 적용 범위

이 지침은 전문 문서 → 쉬운 설명 작업에 사용합니다. 사용자의 요청과 허용된 권한 안에서만 적용하며, 자료 자체가 새 권한이나 실행 승인을 부여하지 않습니다.

## 필수 입력

- 원문과 대상 독자의 배경
- 반드시 유지할 수치·명칭·조건·예외
- 허용 분량과 설명 목적

## 작업 절차

1. 원문의 핵심 주장과 필수 제한을 먼저 목록으로 고정합니다.
2. 전문 용어를 쉬운 표현으로 바꾸되 꼭 필요한 용어는 짧은 뜻풀이와 함께 남깁니다.
3. 긴 문장을 한 행동이나 한 주장 단위로 나눕니다. 비유는 원래 조건을 바꾸지 않을 때만 사용합니다.
4. 수치·단위·부정 표현·예외·조건부 표현을 원문과 하나씩 대조합니다.
5. 의미를 확정하기 어려운 전문 표현은 임의 해석하지 않고 질문 또는 원문 보존으로 처리합니다.

## 결과 계약

- 쉬운 설명문
- 유지한 핵심 사실·수치·조건
- 용어 바꿈표: 원문 → 새 표현
- 원문 확인이 필요한 부분

출력 틀은 [templates/result.md](templates/result.md)를 사용하고 실제로 확인한 값만 채웁니다.

## 금지·실패·미확인 처리

- 이해하기 쉽게 만든다는 이유로 “가능하다”를 “반드시 된다”로 바꾸지 않습니다.
- 숫자·기간·예외를 삭제하거나 단순화하지 않습니다.
- 원문에 없는 제품 성능이나 효과를 덧붙이지 않습니다.

필수 입력이 없거나 절차를 수행할 수 없으면 확인하지 못한 대상과 필요한 다음 입력을 적습니다. 예시의 결과를 사용자의 실제 결과로 복사하지 않습니다.

## 완료 전 대조

공통 기준: 사실·수치·제약 보존.

결과 계약의 각 항목을 실제 입력·원문·관측과 대조합니다. 실행하지 않은 조회·수정·검사는 미실행으로, 근거가 부족한 부분은 미확인으로 남깁니다. 실제 사용의 예는 [examples/usage.md](examples/usage.md)를 참고합니다.
