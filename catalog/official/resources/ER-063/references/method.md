# 대안 비교 Skill: 판단·처리 기준

결측 상태는 unknown, not-applicable, conflicting 세 가지를 구분합니다. 예산은 월 20 단위 이하처럼 분모를 적습니다. 가중 합계를 사용할 때에는 모든 기준의 정규화식·가중치 출처·미확인 처리 정책을 먼저 공개합니다.

## 입력 예의 사용

example-input.json은 가상 한빛팀 상황을 위해 새로 작성한 자료입니다. 예제 값은 실제 사용자 결과가 아닙니다. 실제 자료로 바꿀 때 원문 ID·버전·허용 범위를 보존하세요. 필수 입력을 제거하거나 근거를 바꾸면 성공 결과를 그대로 유지하지 말고 실패·미확인 처리를 적용합니다.
