# Sub Agent 인계 지침 활용 예

아래 입력·상황은 모두 가상 연습자료입니다. 결과는 지침을 어떻게 적용하는지 설명하기 위해 작성한 예이며 실제 모델·외부 서비스 실행 기록이 아닙니다.

## 입력

가상 부모 작업은 보고서 작성이며 하위에는 제공된 표의 합계 검산만 맡깁니다. 네트워크는 필요하지 않습니다.

## 지침을 적용한 설명용 결과

하위 목표는 지정한 표의 행별 합계와 총합 대조입니다. 입력 표 버전과 합산 규칙, 결과 필드 {행ID,기대합계,관측합계,일치}를 전달합니다. 외부 조회와 원본 수정은 허용하지 않습니다.

## 입력이 부족하거나 충돌할 때

표의 통화 단위가 섞였으면 하위 작업은 합산을 확정하지 않고 질문 상태로 상위에 반환합니다.

## 직접 활용하기

자신이 사용할 권한이 있는 자료로 입력을 바꾸고 instructions.md의 절차를 적용하세요. 결과를 원문·실제 관측과 대조하며, 필요한 외부 연결과 권한이 없으면 실행한 것으로 표시하지 마세요.
