# 레코드 추출 Skill: 판단·처리 기준

evidence는 레코드와 분리한 같은 순서의 배열입니다. 한 필드는 한 sourceId와 quote를 가집니다. quote는 원문에 정확히 포함되어야 하며 공백·OCR 정규화는 원문 보존 후 별도 처리합니다. 정수는 integer, 실수 허용은 number로 구분합니다.

## 입력 예의 사용

example-input.json은 가상 한빛팀 상황을 위해 새로 작성한 자료입니다. 예제 값은 실제 사용자 결과가 아닙니다. 실제 자료로 바꿀 때 원문 ID·버전·허용 범위를 보존하세요. 필수 입력을 제거하거나 근거를 바꾸면 성공 결과를 그대로 유지하지 말고 실패·미확인 처리를 적용합니다.
