# 요청 구체화 지침 활용 예

아래 입력·상황은 모두 가상 연습자료입니다. 결과는 지침을 어떻게 적용하는지 설명하기 위해 작성한 예이며 실제 모델·외부 서비스 실행 기록이 아닙니다.

## 입력

가상 요청: “다음 주 팀 회의에서 볼 행사 준비표를 만들어 줘. 장소 예약은 완료했어.” 참석 인원과 행사 날짜는 제공되지 않았습니다.

## 지침을 적용한 설명용 결과

목표는 회의용 행사 준비표 작성입니다. 확정 조건은 장소 예약 완료입니다. 필수 질문은 행사 날짜와 참석 인원입니다. 준비표의 열은 업무·상태·확인 필요 사항으로 가정하고, 담당자와 기한은 미정으로 둡니다.

## 입력이 부족하거나 충돌할 때

“행사를 대신 예약해 줘”만 있으면 결제·장소·날짜가 정해지기 전 예약 도구를 호출하지 않고 필요한 선택만 요청합니다.

## 직접 활용하기

자신이 사용할 권한이 있는 자료로 입력을 바꾸고 instructions.md의 절차를 적용하세요. 결과를 원문·실제 관측과 대조하며, 필요한 외부 연결과 권한이 없으면 실행한 것으로 표시하지 마세요.
