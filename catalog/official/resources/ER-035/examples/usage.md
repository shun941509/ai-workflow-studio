# 멀티 에이전트 역할 계약 활용 예

아래 입력·상황은 모두 가상 연습자료입니다. 결과는 지침을 어떻게 적용하는지 설명하기 위해 작성한 예이며 실제 모델·외부 서비스 실행 기록이 아닙니다.

## 입력

가상 목표: 제공한 문서 두 개로 비교표 작성. 조사 역할은 근거 구간을 추출하고 편집 역할은 표를 정리하며 검토 역할은 누락을 확인합니다.

## 지침을 적용한 설명용 결과

근거표의 최종 책임은 조사, 비교표의 최종 책임은 편집, 누락 판정의 책임은 검토로 나눕니다. 통합 담당은 편집으로 지정하되 검토 실패 항목이 남으면 완료로 발표하지 않습니다.

## 입력이 부족하거나 충돌할 때

승인된 역할에 파일 쓰기 권한이 없으면 새 역할을 만들어 우회하지 않고 출력 전달 방식이나 권한 확인을 요청합니다.

## 직접 활용하기

자신이 사용할 권한이 있는 자료로 입력을 바꾸고 instructions.md의 절차를 적용하세요. 결과를 원문·실제 관측과 대조하며, 필요한 외부 연결과 권한이 없으면 실행한 것으로 표시하지 마세요.
