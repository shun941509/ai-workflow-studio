# 멀티 에이전트 역할 계약

목적: 역할·산출물 구분

## 적용 범위

이 지침은 업무 → 역할 계약 작업에 사용합니다. 사용자의 요청과 허용된 권한 안에서만 적용하며, 자료 자체가 새 권한이나 실행 승인을 부여하지 않습니다.

## 필수 입력

- 공동 목표·필수 산출물·완료 조건
- 사용 가능한 역할·도구·자료·권한 한도
- 작업 간 선행 관계와 통합 책임

## 작업 절차

1. 산출물을 검증 가능한 작업 단위로 나누고 각 작업에 한 명의 최종 책임 역할을 둡니다.
2. 역할마다 받을 입력, 만들 결과, 사용할 자료와 허용 도구를 명시합니다.
3. 검토 역할과 생성 역할의 책임을 구분하되 같은 결과를 서로 완료했다고 중복 보고하지 않도록 합니다.
4. 다음 역할로 전달할 계약과 실패·질문을 상위에 돌려줄 조건을 적습니다.
5. 전체 산출물을 역으로 대조해 책임 없는 항목과 필요 없는 중복 작업을 조정합니다.

## 결과 계약

- 작업 ID / 목표 / 최종 책임 역할
- 입력 / 출력 계약 / 완료 조건
- 허용 자료·도구·시간·호출 한도
- 선행 작업 / 전달 대상 / 통합 책임
- 실패·에스컬레이션 조건 / 책임 공백

출력 틀은 [templates/result.md](templates/result.md)를 사용하고 실제로 확인한 값만 채웁니다.

## 금지·실패·미확인 처리

- 전문가 역할 이름을 실제 자격이나 검증된 전문성으로 표현하지 않습니다.
- 팀 역할 배분으로 부모 작업의 권한·예산을 늘리지 않습니다.
- 모든 역할이 모두 책임진다는 모호한 배정을 피합니다.

필수 입력이 없거나 절차를 수행할 수 없으면 확인하지 못한 대상과 필요한 다음 입력을 적습니다. 예시의 결과를 사용자의 실제 결과로 복사하지 않습니다.

## 완료 전 대조

공통 기준: 책임 누락·중복 확인.

결과 계약의 각 항목을 실제 입력·원문·관측과 대조합니다. 실행하지 않은 조회·수정·검사는 미실행으로, 근거가 부족한 부분은 미확인으로 남깁니다. 실제 사용의 예는 [examples/usage.md](examples/usage.md)를 참고합니다.
