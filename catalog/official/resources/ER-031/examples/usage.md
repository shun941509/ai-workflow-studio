# 구조화 추출 지침 활용 예

아래 입력·상황은 모두 가상 연습자료입니다. 결과는 지침을 어떻게 적용하는지 설명하기 위해 작성한 예이며 실제 모델·외부 서비스 실행 기록이 아닙니다.

## 입력

가상 문서: “요청 코드 R-15, 수량 4개.” 스키마는 request_code, quantity, owner를 요구하고 owner 누락은 null을 허용합니다.

## 지침을 적용한 설명용 결과

레코드는 {"request_code":"R-15","quantity":4,"owner":null}입니다. quantity는 “4개”에서 숫자를 추출한 규칙을 기록하고 owner는 미기재로 표시합니다.

## 입력이 부족하거나 충돌할 때

owner가 필수 문자열이며 null을 허용하지 않으면 추출 완료로 표시하지 않고 필수값 누락 오류를 반환합니다.

## 직접 활용하기

자신이 사용할 권한이 있는 자료로 입력을 바꾸고 instructions.md의 절차를 적용하세요. 결과를 원문·실제 관측과 대조하며, 필요한 외부 연결과 권한이 없으면 실행한 것으로 표시하지 마세요.
