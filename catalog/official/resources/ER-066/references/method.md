# 로그 정리 Skill: 판단·처리 기준

TIMEOUT은 지연 관측이며 외부 변경 실패 확정이 아닙니다. AUTH_DENIED는 해당 요청의 거부이고 계정 전체 장애 확정이 아닙니다. DEPENDENCY_UNAVAILABLE은 의존 응답 부재이며 원인 서비스 책임 판정이 아닙니다. 알려지지 않은 코드는 unknown으로 남깁니다.

## 입력 예의 사용

example-input.json은 가상 한빛팀 상황을 위해 새로 작성한 자료입니다. 예제 값은 실제 사용자 결과가 아닙니다. 실제 자료로 바꿀 때 원문 ID·버전·허용 범위를 보존하세요. 필수 입력을 제거하거나 근거를 바꾸면 성공 결과를 그대로 유지하지 말고 실패·미확인 처리를 적용합니다.
