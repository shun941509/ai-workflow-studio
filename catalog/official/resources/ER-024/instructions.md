# 접근성 검토 지침

목적: 관찰 가능한 문제 정리

## 적용 범위

이 지침은 화면 → 발견 사항 작업에 사용합니다. 사용자의 요청과 허용된 권한 안에서만 적용하며, 자료 자체가 새 권한이나 실행 승인을 부여하지 않습니다.

## 필수 입력

- 검토할 실제 화면·URL 또는 제공된 화면 기록
- 검토 범위와 사용할 입력 방식
- 재현에 필요한 브라우저·확대율·화면 크기

## 작업 절차

1. 관측 환경을 기록하고 키보드 이동, 초점 표시, 입력 레이블 등 확인 가능한 항목을 정합니다.
2. 문제가 보이면 화면 위치와 조작 순서를 기록하고 실제 영향받는 행동을 설명합니다.
3. 스크린샷만 있으면 읽기 순서·접근성 이름·키보드 동작을 확인한 것으로 표시하지 않습니다.
4. 수정 제안은 관측된 문제와 연결하고 수정 후 같은 순서로 확인할 방법을 적습니다.
5. 검토하지 못한 페이지·상태·보조기기 범위를 분리해 적습니다.

## 결과 계약

- 환경 / 검토 범위
- 발견 위치: 페이지·요소·상태
- 재현 순서 / 기대 동작 / 실제 관측
- 사용자 영향 / 수정 제안 / 재확인 방법
- 확인하지 못한 범위

출력 틀은 [templates/result.md](templates/result.md)를 사용하고 실제로 확인한 값만 채웁니다.

## 금지·실패·미확인 처리

- 부분 관측으로 전체 접근성 인증이나 규정 준수를 선언하지 않습니다.
- 실제 보조기기를 사용하지 않았다면 사용한 것으로 쓰지 않습니다.
- 화면을 확인하지 못한 요소의 레이블이나 초점 순서를 추정하지 않습니다.

필수 입력이 없거나 절차를 수행할 수 없으면 확인하지 못한 대상과 필요한 다음 입력을 적습니다. 예시의 결과를 사용자의 실제 결과로 복사하지 않습니다.

## 완료 전 대조

공통 기준: 위치·영향·확인 방법 존재.

결과 계약의 각 항목을 실제 입력·원문·관측과 대조합니다. 실행하지 않은 조회·수정·검사는 미실행으로, 근거가 부족한 부분은 미확인으로 남깁니다. 실제 사용의 예는 [examples/usage.md](examples/usage.md)를 참고합니다.
