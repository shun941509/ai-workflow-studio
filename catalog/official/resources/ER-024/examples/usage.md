# 접근성 검토 지침 활용 예

아래 입력·상황은 모두 가상 연습자료입니다. 결과는 지침을 어떻게 적용하는지 설명하기 위해 작성한 예이며 실제 모델·외부 서비스 실행 기록이 아닙니다.

## 입력

가상 관측: Tab으로 “다음” 버튼에 이동했지만 초점 표시가 보이지 않습니다. Enter로 누르면 다음 단계로 이동합니다.

## 지침을 적용한 설명용 결과

발견 사항은 버튼 초점의 시각적 식별 어려움입니다. 키보드 활성화 자체는 작동한 것으로 기록합니다. 버튼 focus-visible 표시 추가 후 같은 Tab 순서로 재확인합니다.

## 입력이 부족하거나 충돌할 때

이미지만 제공되면 초점 표시 문제를 확정하지 않고 실제 키보드 관측이 필요하다고 표시합니다.

## 직접 활용하기

자신이 사용할 권한이 있는 자료로 입력을 바꾸고 instructions.md의 절차를 적용하세요. 결과를 원문·실제 관측과 대조하며, 필요한 외부 연결과 권한이 없으면 실행한 것으로 표시하지 마세요.
