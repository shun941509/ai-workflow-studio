# 제품 FAQ 지식집

RAG 원본 제공. 이 폴더는 실제 내용이 있는 가상 문서·데이터이며 빈 양식이 아닙니다.

## 활용

질문 → 답변 근거. document.md를 원본으로 사용하고 document.md에서 기준과 한계를 확인하세요. 문서 ID·절·행·페이지를 결과의 근거로 남깁니다.

연결 설계: knowledge·retrieval. 필요한 실제 모델·검색·추출·그래프 기능과 접근 권한은 사용자가 준비해야 합니다. 가져오기만으로 실행되거나 권한이 늘어나지 않습니다.

## 자료와 정답의 구분

가상 원문과 설명용 정답을 실제 고객 정보 또는 실제 모델 실행 결과로 표현하지 마세요. 평가용 질문·정답은 검색 원문 인덱스와 분리합니다. PDF·OCR 위치는 파일에 적힌 좌표계와 단위를 확인합니다.

## 결과 확인

정답·답변 불가 질문 구분. 원본과 결과를 직접 대조합니다. 파일 제작·무결성 검사는 실제 호스트 사용이나 검색·OCR 품질 검증을 대신하지 않습니다.

## 이용 조건

LICENSE.md에 이 새로 작성한 원본 자료의 사용·수정·재배포 조건을 제공합니다. 제3자 자료의 권리는 부여하지 않습니다. 모든 기관·제품·역할·수치·사건은 가상입니다.
