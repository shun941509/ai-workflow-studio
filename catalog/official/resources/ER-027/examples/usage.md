# 운영 담당자 관점 활용 예

아래 입력·상황은 모두 가상 연습자료입니다. 결과는 지침을 어떻게 적용하는지 설명하기 위해 작성한 예이며 실제 모델·외부 서비스 실행 기록이 아닙니다.

## 입력

가상 사건: 14:10부터 일부 보고서 생성이 실패합니다. 조회 기능은 정상이고 담당자는 아직 정해지지 않았습니다.

## 지침을 적용한 설명용 결과

보고서 생성 일부 실패, 조회 정상이라는 확인 범위를 먼저 적습니다. 담당은 미정으로 두고 생성 실패 로그 확인과 다음 상태 보고 시점 결정을 요청합니다. 전체 서비스 장애로 확대 표현하지 않습니다.

## 입력이 부족하거나 충돌할 때

복구 확인 기록이 없으면 “조치 적용, 복구 확인 대기”로 표시하고 완료로 바꾸지 않습니다.

## 직접 활용하기

자신이 사용할 권한이 있는 자료로 입력을 바꾸고 instructions.md의 절차를 적용하세요. 결과를 원문·실제 관측과 대조하며, 필요한 외부 연결과 권한이 없으면 실행한 것으로 표시하지 마세요.
