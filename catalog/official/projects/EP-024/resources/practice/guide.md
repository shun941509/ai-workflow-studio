# 초보 고객 온보딩 점검 실습 안내

가상 기관·자료를 사용한 원본 실습입니다. sample-input.json에는 목적별 실제 입력이 있습니다. 실제 고객·개인정보나 모델 답변을 포함하지 않습니다.

입력: 시작 안내 → 혼동·누락 목록.

1. S1의 워크스페이스 의미·진입 위치와 보드 만들기 위치가 불충분함을 원문으로 설명해야 합니다.
2. S2의 명시된 저장 후 위치를 누락으로 잘못 지적하지 않아야 합니다.
3. S3의 관리자 찾기 미준비를 구체적으로 기록하고 실제 인터뷰·성공률을 만들지 않아야 합니다.

화면을 열거나 실제 사용자 행동을 측정하지 않습니다. 텍스트 안내만 검토합니다.
