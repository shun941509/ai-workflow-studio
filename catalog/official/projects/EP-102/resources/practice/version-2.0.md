# 가상 바람노트 2.0 — 자료 내보내기 문제 해결

문서 ID: BN-EXPORT-2.0
적용 제품: 가상 바람노트 2.0
판본: 원작 연습자료 1판
출처: AI Workflow Studio가 이 예제를 위해 직접 작성한 가상 제품 설명입니다. 실제 제품·고객·지원 정책이 아닙니다.

## T1 적용 범위
이 문서는 2.0의 내보내기 작업 화면에만 적용됩니다. 작업을 시작하기 전에 앱 정보에서 버전 2.0을 확인합니다. 다른 버전의 메뉴를 대체 경로로 제시하지 않습니다.

## T2 정상 내보내기
자료→내보내기 작업을 열고 범위와 형식 CSV 또는 JSON을 선택합니다. 한 작업의 한도는 2000행입니다. 미리보기를 확인한 후 작업 만들기를 누르고 작업 상태가 준비됨일 때 결과 받기를 선택합니다. 다운로드 전 작업 ID·행 수·형식을 확인합니다.

## T3 EXPORT-20 범위 초과
증상은 EXPORT-20과 함께 작업 생성이 거절되는 것입니다. 미리보기 행 수를 확인하고 2000행 이하의 서로 겹치지 않는 범위로 나눕니다. 각 작업 ID와 범위를 기록해 빠진 항목과 중복 항목을 대조합니다. 관리자 권한을 늘리거나 기존 자료를 삭제하지 않습니다.

## T4 EXPORT-21 결과 준비 지연
이미 작업 ID가 표시되면 새 작업을 반복 생성하지 않습니다. 같은 작업의 상세 상태를 한 번 확인하고 대기 중이면 기다림으로 기록합니다. 실패 상태이면 오류 코드와 작업 ID를 지원 요청 초안에 적습니다. 상태를 모르면 성공이나 실패로 단정하지 않습니다. 이 자료에는 보장 대기 시간이 없습니다.

## T5 JSON 구조 확인
JSON 파일의 items 배열과 manifest.rowCount를 비교합니다. 두 값이 다르면 불완전 결과로 남기고 가져온 원본을 보존합니다. 지원 연락처·비용·실제 서비스 주소는 이 문서에 없습니다.
