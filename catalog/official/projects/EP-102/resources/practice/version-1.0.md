# 가상 바람노트 1.0 — 자료 내보내기 문제 해결

문서 ID: BN-EXPORT-1.0
적용 제품: 가상 바람노트 1.0
판본: 원작 연습자료 1판
출처: AI Workflow Studio가 이 예제를 위해 직접 작성한 가상 제품 설명입니다. 실제 제품·고객·지원 정책이 아닙니다.

## S1 적용 범위
이 문서는 1.0의 데스크톱 내보내기에만 적용됩니다. 다른 버전의 화면·기능을 추론하지 않습니다. 실행 전 앱 정보에서 버전 1.0을 확인합니다. 관리자 권한 변경이나 파일 삭제를 요구하지 않습니다.

## S2 정상 내보내기
저장한 항목을 CSV로 내보내려면 보관함→자료 내보내기를 엽니다. 기간을 선택하고 미리보기 행 수를 확인한 뒤 CSV 저장을 누릅니다. 한 번에 최대 500행이며 파일은 사용자가 고른 위치에 저장합니다. 저장 결과의 행 수와 미리보기 행 수를 비교합니다.

## S3 EXPORT-10 행 수 초과
증상은 EXPORT-10과 함께 저장 버튼이 비활성화되는 것입니다. 미리보기가 500행을 초과하는지 확인합니다. 500행 이하가 되도록 기간을 나누고 각 기간을 따로 저장합니다. 기간 경계에 중복 항목이 없는지 항목 ID로 대조합니다. 기간을 줄여도 오류가 남으면 오류 코드·버전·행 수만 지원 요청 초안에 적고 원문 데이터는 자동 전송하지 않습니다.

## S4 저장 후 열이 깨져 보임
이 버전의 CSV 문자 인코딩은 UTF-8입니다. 스프레드시트 가져오기에서 UTF-8과 쉼표 구분자를 명시하고 원본 CSV는 보존합니다. 인코딩 재저장 전에 제목·한글·구분자 열을 확인합니다.

## S5 미기재 사항
이 문서는 지원 연락처, 서비스 비용, 서버 보존 기간을 정의하지 않습니다. 이 절차가 모든 장애를 해결한다고 보증하지 않습니다. 성공 확인이 없으면 완료라고 보고하지 않습니다.
