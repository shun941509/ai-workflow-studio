# 출처 위치 지침 활용 예

아래 입력·상황은 모두 가상 연습자료입니다. 결과는 지침을 어떻게 적용하는지 설명하기 위해 작성한 예이며 실제 모델·외부 서비스 실행 기록이 아닙니다.

## 입력

가상 PDF의 파일 5번째 페이지에 인쇄 번호 3이 있고, “신청 조건” 절에 “예약은 2일 전까지”라는 문장이 있습니다.

## 지침을 적용한 설명용 결과

인용은 “예약은 2일 전까지”로 쓰고 문서 D-3 v1, 파일 페이지 5, 표시 페이지 3, 신청 조건 절로 연결합니다.

## 입력이 부족하거나 충돌할 때

텍스트만 있고 페이지 매핑이 없으면 페이지 번호를 만들지 않고 제공 본문 내 절 위치와 원본 확인 필요를 표시합니다.

## 직접 활용하기

자신이 사용할 권한이 있는 자료로 입력을 바꾸고 instructions.md의 절차를 적용하세요. 결과를 원문·실제 관측과 대조하며, 필요한 외부 연결과 권한이 없으면 실행한 것으로 표시하지 마세요.
