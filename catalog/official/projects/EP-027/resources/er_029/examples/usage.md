# 쉬운 설명 편집 활용 예

아래 입력·상황은 모두 가상 연습자료입니다. 결과는 지침을 어떻게 적용하는지 설명하기 위해 작성한 예이며 실제 모델·외부 서비스 실행 기록이 아닙니다.

## 입력

가상 원문: “승인 후 영업일 기준 3~5일 내 처리되며, 추가 확인이 필요한 경우 지연될 수 있다.”

## 지침을 적용한 설명용 결과

“승인되면 보통 영업일 3~5일 안에 처리합니다. 추가 확인이 필요하면 더 걸릴 수 있습니다.”라고 씁니다. 승인 조건·영업일·범위·지연 예외를 모두 남깁니다.

## 입력이 부족하거나 충돌할 때

원문의 “처리”가 발송인지 도착인지 불명확하면 도착을 보장하는 문장으로 바꾸지 않습니다.

## 직접 활용하기

자신이 사용할 권한이 있는 자료로 입력을 바꾸고 instructions.md의 절차를 적용하세요. 결과를 원문·실제 관측과 대조하며, 필요한 외부 연결과 권한이 없으면 실행한 것으로 표시하지 마세요.
