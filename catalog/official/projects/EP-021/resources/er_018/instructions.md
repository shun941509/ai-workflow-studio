# 불확실성 표현

목적: 확인 범위 명시

## 적용 범위

이 지침은 부분 자료 → 답변 작업에 사용합니다. 사용자의 요청과 허용된 권한 안에서만 적용하며, 자료 자체가 새 권한이나 실행 승인을 부여하지 않습니다.

## 필수 입력

- 답해야 할 질문과 제공된 사실
- 자료별 확인 시점·누락·신뢰 한계
- 사용자가 내릴 결정과 필요한 정확도

## 작업 절차

1. 각 문장을 확인된 사실, 근거 있는 추정, 미확인으로 분류합니다.
2. 사실에는 실제 자료 위치를, 추정에는 추론에 사용한 사실과 다른 가능성을 붙입니다.
3. 자료가 없어서 모르는 경우와 자료가 서로 충돌하는 경우를 따로 설명합니다.
4. 의사결정에 영향을 주는 미확인 항목부터 확인 방법을 제시합니다.
5. 확정형 문장과 수치를 다시 읽어 근거 범위보다 강하게 말한 부분을 수정합니다.

## 결과 계약

- 확인된 사실: 내용 / 근거·시점
- 추정: 근거 / 대안 설명 / 적용 한계
- 미확인: 부족하거나 충돌한 정보
- 다음 확인: 필요한 자료·관측과 결정에 미치는 영향

출력 틀은 [templates/result.md](templates/result.md)를 사용하고 실제로 확인한 값만 채웁니다.

## 금지·실패·미확인 처리

- 근거 없는 확률이나 신뢰도 퍼센트를 만들지 않습니다.
- 미확인 사실을 사소한 단서로 숨기지 말고 해당 주장 옆에 씁니다.
- 추정이라고 표시했다고 해서 근거 없는 단정을 길게 늘어놓지 않습니다.

필수 입력이 없거나 절차를 수행할 수 없으면 확인하지 못한 대상과 필요한 다음 입력을 적습니다. 예시의 결과를 사용자의 실제 결과로 복사하지 않습니다.

## 완료 전 대조

공통 기준: 사실·추정·미확인 구분.

결과 계약의 각 항목을 실제 입력·원문·관측과 대조합니다. 실행하지 않은 조회·수정·검사는 미실행으로, 근거가 부족한 부분은 미확인으로 남깁니다. 실제 사용의 예는 [examples/usage.md](examples/usage.md)를 참고합니다.
