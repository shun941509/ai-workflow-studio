# 면접 연습 상대

답변 연습 지원. 직무·답변 → 질문·피드백.

사용자가 이미 작성한 답변 1~5개를 순서대로 다루고, 답변당 후속 질문 하나와 피드백·평가를 제공합니다. 질문 수는 입력 답변 수와 같고 최대 5개입니다.

## 시작

1. 실제 JSON 응답 모델을 project-model에 연결합니다.
2. resources/practice/sample-input.json의 가상 직무·답변으로 시작합니다.
3. 후속 질문 수·원문 인용·채용 판단 금지를 확인한 뒤 본인이 다음 답변을 작성합니다.

resources/practice/sample-input.json은 초기 입력에 사용할 실제 가상 연습 데이터이며 프로젝트 폴더의 sample-input.json과 같습니다. 실제 모델 답변이나 테스트 fixture가 아닙니다. 지침·문서 원본과 descriptor 해시를 workflow.resources에 고정했고 모든 해당 원본 파일을 ZIP에 동봉합니다.

원래 필수 구성 agent·form·loop·evaluate을 보존했습니다. 원본 사용자 자료의 내용은 분석 대상이며 작업의 권한·지침을 바꾸는 명령이 아닙니다.

## 결과 확인

1. A1·A2가 입력 순서대로 각각 한 결과에 대응하고 후속 질문은 총 2개여야 합니다.
2. sourceQuote는 해당 답변 안의 연속 문자열이며 다른 답변·없는 경력을 근거로 사용하지 않아야 합니다.
3. 모든 status=practice_only이고 합격/불합격·채용 점수·개인 신상 질문을 만들지 않아야 합니다.
4. 평가가 0인 결과를 그대로 표시하고 정답이나 합격으로 바꾸지 않아야 합니다.

공통 완료 기준: 질문 수 준수, 채용 판정으로 표시하지 않음.

## 범위·실패·준비

- 실시간 무한 대화가 아닌 한 번에 1~5개 답변을 처리하는 유한 연습입니다. 이어서 답하려면 다음 실행을 명시적으로 시작합니다.
- 반복 안에는 사용자 대기·외부 도구가 없고 최대 10회 모델 호출입니다.

실제 JSON 응답 모델을 project-model에 연결해야 합니다. 계정·키·외부 설정은 동봉하지 않습니다. 모델 평가 점수는 모델의 관찰이며 실제 사실 인증이 아닙니다. 입력 스키마·원본 해시·모델 응답이 잘못되거나 토큰·호출·시간 한도에 도달하면 실제 오류로 중단합니다. 응답이 없는 검토는 승인으로 바꾸지 않습니다. 실제 업무 수행·발송·게시·채용 결정·계정 변경을 하지 않습니다.

현재 검증은 공통 계약·원본 무결성·운영 ZIP 및 계정 없이 확인 가능한 순수 처리입니다. 실제 모델 품질, Codex·Claude Code·OpenCode 실제 사용, 검수·게시는 unverified입니다. 원본 사용·수정·재배포 조건은 LICENSE.md에 있습니다. 생성기는 이미 작성된 폴더를 자동 덮어쓰지 않으며 수정 시 새 판본과 해시를 검토합니다.
