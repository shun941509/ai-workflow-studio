# 반대 검토자 가정 점검 실습 안내

가상 기관·자료를 사용한 원본 실습입니다. sample-input.json에는 목적별 실제 입력이 있습니다. 실제 고객·개인정보나 모델 답변을 포함하지 않습니다.

입력: 계획·근거 → 반례·확인 실험.

1. A1은 E1의 3건 중 1건과 전체 통계 부재를 보존해야 합니다.
2. A2의 근거 없음과 모든 유형이라는 일반화의 확인 필요를 명시해야 합니다.
3. 지적마다 관측 방법·기각 조건이 있고 status=hypothesis를 유지해야 합니다.

외부 분석·설문·실험 도구를 호출하지 않습니다. 검토 관점과 실험 설계만 제공합니다.
