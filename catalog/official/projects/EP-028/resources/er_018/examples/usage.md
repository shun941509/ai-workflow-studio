# 불확실성 표현 활용 예

아래 입력·상황은 모두 가상 연습자료입니다. 결과는 지침을 어떻게 적용하는지 설명하기 위해 작성한 예이며 실제 모델·외부 서비스 실행 기록이 아닙니다.

## 입력

가상 로그에서 오전 9시에 오류 4건이 확인됩니다. 같은 시각 배포가 있었다는 동료의 메모는 있지만 배포 기록은 없습니다.

## 지침을 적용한 설명용 결과

사실은 오전 9시 오류 4건입니다. 배포와의 관련성은 확인할 가설이며 배포 시각·변경 내역이 필요합니다. “배포가 원인이다”라고 확정하지 않습니다.

## 입력이 부족하거나 충돌할 때

집계 기간이 없으면 증가율을 계산하지 않고 기간 확인 전 수치 비교를 보류합니다.

## 직접 활용하기

자신이 사용할 권한이 있는 자료로 입력을 바꾸고 instructions.md의 절차를 적용하세요. 결과를 원문·실제 관측과 대조하며, 필요한 외부 연결과 권한이 없으면 실행한 것으로 표시하지 마세요.
