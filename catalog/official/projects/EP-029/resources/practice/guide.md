# 다국어 독자 안내 개선 실습 안내

가상 기관·자료를 사용한 원본 실습입니다. sample-input.json에는 목적별 실제 입력이 있습니다. 실제 고객·개인정보나 모델 답변을 포함하지 않습니다.

입력: 원문·용어집 → 번역·확인표.

1. 초안·검토·결과 불명·재시도가 고정 용어와 의미에 맞게 번역되어야 합니다.
2. 세 preserveTokens가 번역문에 바이트 단위 같은 문자열로 남아야 합니다.
3. 결과 불명에서 재시도하지 말라는 부정을 보존하고 링크 접근·전문가 감수 완료를 주장하지 않아야 합니다.

현재 예제 용어집은 한국어→영어입니다. 다른 언어/용어는 자료와 입력 계약의 새 판본을 준비해야 합니다.
example.com 링크는 가상 예시 문자열로 보존하며 실제로 열지 않습니다.
