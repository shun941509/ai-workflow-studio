# 다국어 독자 관점 활용 예

아래 입력·상황은 모두 가상 연습자료입니다. 결과는 지침을 어떻게 적용하는지 설명하기 위해 작성한 예이며 실제 모델·외부 서비스 실행 기록이 아닙니다.

## 입력

가상 원문: “Submit by 2026-11-05 17:00 KST. Product code AX-7 must remain unchanged.” 대상 언어는 한국어입니다.

## 지침을 적용한 설명용 결과

“2026년 11월 5일 오후 5시(한국 표준시)까지 제출하세요. 제품 코드 AX-7은 변경하면 안 됩니다.”로 제안합니다. 코드·기한·시간대·금지 강도를 대조표에 남깁니다.

## 입력이 부족하거나 충돌할 때

“Submit by 03/04”만 있으면 날짜를 확정하지 않고 작성자의 날짜 형식과 연도를 확인합니다.

## 직접 활용하기

자신이 사용할 권한이 있는 자료로 입력을 바꾸고 instructions.md의 절차를 적용하세요. 결과를 원문·실제 관측과 대조하며, 필요한 외부 연결과 권한이 없으면 실행한 것으로 표시하지 마세요.
