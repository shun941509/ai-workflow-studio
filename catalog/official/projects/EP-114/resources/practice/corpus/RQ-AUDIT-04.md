# 가상 온솔 기록보관함 — 요구사항 검토 근거

출처 ID: RQ-AUDIT-04 / 원작 가상 감사 기록 규칙 1판
실제 감사 인증이나 보안 증명서가 아닙니다.

## L1 남기는 항목
기록 변경에는 작업 ID, 주체의 내부 ID, 대상 ID, 수행 상태, 시각을 남깁니다. 원문 내용·API 키·인증 토큰은 변경 이벤트에 기록하지 않습니다.

## L2 불명 결과
전송 뒤 응답을 잃으면 성공으로 표시하지 않습니다. 변경 확인 전 자동 재실행하지 않고 담당자 확인 대상으로 남깁니다.

## L3 증명 범위
이 규칙은 외부 기관의 감사 인증이나 위변조 방지 서명 구현을 입증하지 않습니다. 감사 로그 보관 기간은 별도 계약에 따라야 하며 여기에는 숫자가 없습니다.
