# 가상 온솔 기록보관함 — 요구사항 검토 근거

출처 ID: RQ-ACL-03 / 원작 가상 권한 명세 1판
예제용 명세이며 실제 계정 권한이 아닙니다.

## A1 역할
작성자는 자신의 초안을 작성·조회할 수 있습니다. 검토자는 배정된 초안을 읽고 의견을 남길 수 있습니다. 운영자는 승인된 요청의 처리 상태를 확인합니다. 검토 의견 제출은 원본 삭제나 외부 발송 승인이 아닙니다.

## A2 조직 범위
서로 다른 작업 조직의 기록은 공유하지 않습니다. 실제 구현에서는 현재 조직·주체·대상 기록 권한을 서버가 확인해야 합니다. 이 문서를 검색했다는 사실은 권한 필터 검증 증거가 아닙니다.
