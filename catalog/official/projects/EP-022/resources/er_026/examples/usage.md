# 초보 사용자 관점 활용 예

아래 입력·상황은 모두 가상 연습자료입니다. 결과는 지침을 어떻게 적용하는지 설명하기 위해 작성한 예이며 실제 모델·외부 서비스 실행 기록이 아닙니다.

## 입력

가상 안내: “토큰을 설정한 후 재시도하세요.” 화면에는 “연결 설정” 버튼만 있습니다.

## 지침을 적용한 설명용 결과

“토큰”의 의미와 입력 위치가 설명되지 않았다고 표시합니다. “연결 설정을 열어 서비스 연결 정보를 확인한 뒤 다시 시도하세요”를 제안하되 실제 입력 항목은 화면 확인 후 구체화합니다.

## 입력이 부족하거나 충돌할 때

설정 화면을 보지 못했다면 존재하지 않는 탭 이름을 써 넣지 않고 확인 필요로 둡니다.

## 직접 활용하기

자신이 사용할 권한이 있는 자료로 입력을 바꾸고 instructions.md의 절차를 적용하세요. 결과를 원문·실제 관측과 대조하며, 필요한 외부 연결과 권한이 없으면 실행한 것으로 표시하지 마세요.
