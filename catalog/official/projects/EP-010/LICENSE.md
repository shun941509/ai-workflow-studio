# Studio 원본 예제 프로젝트 이용 조건 v1

AI Workflow Studio 원본 예제 프로젝트 EP-010의 워크플로·지침·문서·가상 입력은 새로 작성한 원본입니다. 개인·교육·업무·상업적 사용, 복제, 수정 및 재배포를 허용합니다. 재배포 시 이 조건과 위 출처를 유지하고 수정 사실을 표시하세요. 동봉된 각 공식 지침은 해당 폴더의 이용 조건을 함께 유지하세요.
