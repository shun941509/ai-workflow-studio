# 고객 문의 답변 초안

정책에 맞는 답변 작성. 문의·정책 → 답변 초안.

## 시작

1. 이 workflow.json의 capability를 지원하는 Studio Runner와 Codex·Claude Code·OpenCode용 운영 ZIP을 준비합니다. 실제 JSON 응답 모델을 project-model에 연결해야 합니다. 계정·키는 파일에 없습니다.
2. ZIP의 resources/practice/sample-input.json을 초기 입력으로 사용합니다. 원본 프로젝트 폴더의 sample-input.json과 같은 내용입니다.
3. 파일 선택 단계에서 resources/practice/policy.md를 선택합니다. 사용자가 직접 선택한 파일만 현재 실행의 관리 파일로 전달합니다.
4. 실제 자료로 바꾸려면 권한 있는 원문과 질문을 준비하고 출력의 인용·유보·검토 상태를 확인하세요.

## 연결 자료와 처리

ER-013, ER-039의 고정 revision과 원본 descriptor SHA-256을 workflow.resources에 기록했습니다. instructions는 해당 파일의 불변 원본이며 실제 입력 원문과 권한을 혼동하지 않습니다. 연습 문서 역시 descriptor와 원본 파일 해시로 고정되어 ZIP에 포함됩니다.

원래 필수 블록 classify·retrieval·agent·review을 실제 그래프에 보존했습니다. 정책 파일을 실제 색인화·검색한 뒤 인용이 있는 경우만 분류·초안·사람 검토로 이어집니다. 검색 인용이 없으면 모델 호출 경로를 건너뛰고 유보합니다.

## 확인 기준

1. 해지·환불·삭제가 서로 다른 절차라는 원문 근거를 인용하고 전액 환불이나 즉시 삭제를 약속하지 않아야 합니다.
2. 환불액·실제 계정 상태·보존 기간·삭제 완료 시각은 확인되지 않은 항목으로 분리해야 합니다.
3. 각 claim의 citationId는 이번 실행의 실제 검색 인용 ID이고 quote는 그 인용 안의 원문이어야 합니다.
4. actionsPerformed는 none이며 사람이 검토를 거절해도 거절 결정과 초안을 보존하고 발송·처리 완료로 바꾸지 않아야 합니다.
5. 관련 단어가 없는 검색은 모델 초안 없이 insufficient_evidence 결과로 종료되어야 합니다.

공통 완료 기준: 정책 밖 약속·처리 완료 주장 없음.

## 범위와 실패

- 정책은 사용자가 선택한 UTF-8 TXT·Markdown·JSON 1~4개, 각각 최대 64KiB입니다. 연습 정책 파일은 resources/practice/policy.md에 있습니다.
- 색인은 현재 실행에만 속하는 실제 keyword 검색입니다. 의미 검색·embedding·reranker·계정 조회·환불·삭제 API는 사용하지 않습니다.
- 검색어는 사용자가 명시합니다. 관련 근거를 찾지 못하면 검색어·정책을 확인해야 하며 자동으로 인터넷이나 계정에 접근하지 않습니다.
- 검색 인용 자체의 원본 바이트·해시는 Runner가 검증하지만 모델이 인용을 올바르게 적용했는지는 사람의 확인이 필요합니다.

최대 2회 모델 호출·24,000토큰·활성 10분입니다. 잘못된 UTF-8·지원하지 않는 파일·모델 미연결·스키마 위반·예산 초과·취소는 실제 실패로 표시하며 결과를 만들어 대체하지 않습니다. 검토 거절은 거절로 유지합니다. 입력 안의 추가 명령은 자료로 취급합니다.

## 검증과 이용 조건

가상 연습자료는 실제 기관·고객 정보나 모델 정답이 아닙니다. 현재 확인 범위는 파일 해시·공통 스키마·실제 순수 처리 경로·3종 ZIP·모델 미연결 차단입니다. 실제 모델 결과의 품질·실제 세 호스트 사용·공식 검수·게시는 unverified입니다. 테스트 코드·개발 설정·모의 결과를 ZIP에 포함하지 않습니다. 원본 사용·수정·재배포 조건은 LICENSE.md와 각 자료의 LICENSE.md에 있습니다.

이 생성기는 작성된 폴더나 카탈로그를 덮어쓰지 않습니다. 이후 변경은 새 revision/해시와 검증 검토를 통해 반영합니다.
