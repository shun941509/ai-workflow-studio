# 가상 북극 문서 API 1.0 — 목록 조회 계약

문서 ID: POLAR-LIST-1.0
API 버전: 1.0
원작 가상 기술 문서입니다. 실제 서버나 호출 가능한 주소는 제공하지 않습니다.

## A1 목록 요청
계약상 목록 경로는 GET /v1/documents입니다. page는 1부터 시작하는 정수이고 page_size는 1~50이며 기본값은 20입니다. 요청은 조회만 표현하며 이 예제는 실제 HTTP 요청을 실행하지 않습니다.

## A2 응답과 다음 페이지
응답은 documents 배열과 page, total_pages를 포함합니다. 각 문서는 id, title, updated_at 필드를 가집니다. 다음 페이지는 page가 total_pages보다 작을 때 page를 1 늘려 요청합니다. 빈 documents 배열만으로 전체 데이터 삭제를 뜻하지 않습니다.

## A3 정렬과 변경 중 조회
기본 정렬은 updated_at 내림차순입니다. 여러 페이지를 읽는 동안 원본이 변경되면 페이지 경계가 이동해 같은 id가 다시 나타날 수 있습니다. 클라이언트는 id로 중복을 기록합니다. 이 문서는 일관된 스냅샷을 보장하지 않습니다.

## A4 오류
잘못된 page 또는 page_size는 INVALID_PAGE입니다. 오류에는 요청 필드 이름을 포함하지만 인증 비밀은 포함하지 않습니다. 인증 방식·할당량·요금·서비스 주소는 이 문서의 범위 밖이며 추정하지 않습니다.
