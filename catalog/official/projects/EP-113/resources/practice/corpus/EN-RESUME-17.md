# Fictional Cedar Desk — resuming a review

Source ID: EN-RESUME-17. Rule ID: CD-R17. Original fictional operating note authored for AI Workflow Studio. This is not a real service policy or customer record.

A review may resume from an acknowledged checkpoint when the saved revision and the pending review item still match. Resume continues the same work; it does not send the earlier external operation again.

If the operation outcome is unknown, preserve the operation ID and ask for status reconciliation before any retry. A missing response is not proof that nothing happened. CD-R17 does not authorize publishing, sending mail, or changing permissions.

For an expired review item, create a new review request tied to the current revision. Do not copy an old acceptance into the new request. No expiry duration is specified in this note.
