# 교육 퀴즈 설계 실습 안내

가상 기관·자료를 사용한 원본 실습입니다. sample-input.json에는 목적별 실제 입력이 있습니다. 실제 고객·개인정보나 모델 답변을 포함하지 않습니다.

입력: 자료·목표 → 문제·해설.

1. 연습 입력은 문항 2개이며 G1/G2를 실제 P1/P2 근거와 연결해야 합니다.
2. 정답·해설·선택지가 일관되고 “문의 접수=완료”를 정답으로 만들지 않아야 합니다.
3. 세 평가 기준이 모두 1일 때만 quizzes.json을 저장하며 미충족 평가는 결과에 그대로 남겨야 합니다.

평가는 다른 모델 호출의 확인입니다. 교육 담당자가 정답·모호성·수준을 실제 원문과 최종 대조해야 합니다.
저장 파일은 Runner 관리 영역의 outputs/quizzes.json이며 원본 자료를 수정하지 않습니다.
