# 가상 구름서가 — 미사용 상품 반품 정책

문서 ID: CLOUD-RETURN-1
문서범위: 미사용 상품 반품 접수 조건과 절차
자료 성격: AI Workflow Studio가 직접 작성한 원작 가상 연습문서입니다. 실제 상점·주문·결제·고객 정책이 아닙니다.

## R1 접수 조건
반품 접수는 수령일부터 14일 이내에 가능합니다. 미사용 상품이고 원래 포장과 구성품이 보존되어 있어야 합니다. 날짜 조건만 맞는다고 사용한 상품이 자동 승인되는 것은 아닙니다.

## R2 접수 절차
주문 식별번호, 수령일, 미사용 여부, 포장·구성품 보존 여부를 정리한 요청 초안을 만듭니다. 접수한 요청의 상태가 확인될 때까지 승인 완료나 환급 완료라고 표시하지 않습니다. 이 예제는 요청 초안을 실제 전송하지 않습니다.

## R3 미기재 사항
반품 비용 금액, 환급 완료까지의 일수, 실제 접수 주소, 파손 상품의 예외 처리는 이 문서에 없습니다. 원문에 없는 비용·연락처·예외를 일반 상식으로 채우지 않습니다. 판단에 필요한 사실이 부족하면 답변을 유보합니다.
