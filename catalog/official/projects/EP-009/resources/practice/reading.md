# 가상 한빛 자료실 도입 안내 v1

이 문서는 가상 조직과 제품을 위한 연습자료이며 실제 고객·기관 정보가 없습니다.

## 1. 자료실의 범위
자료실은 공지와 업무 안내를 읽는 공간입니다. 이번 시험 도입 범위는 읽기 전용입니다. 문서 수정과 계정 권한 변경은 이 안내의 범위에 포함하지 않습니다.

## 2. 자료 찾기
상단 검색에서 업무 이름을 입력한 뒤 제목과 개정일을 확인합니다. 같은 제목이 있으면 승인 상태가 “현재”인 자료를 먼저 읽습니다. 검색 결과의 요약만으로 정책을 확정하지 않고 원문을 엽니다.

## 3. 질문과 오류 신고
안내에서 답을 찾지 못하면 문의 접수 양식에 문서 제목, 개정일, 확인한 구간, 질문을 적습니다. 개인정보나 인증정보를 붙이지 않습니다. 접수는 담당 확인 대기 상태이며 처리 완료를 의미하지 않습니다.

## 4. 공개 전 확인
읽기 전용 시험 도입 담당은 현재 문서가 검색되는지, 오래된 판본이 구분되는지, 문의 양식이 열리는지 확인합니다. 실제 게시와 권한 변경은 별도 승인 절차를 따릅니다.

## 5. 아직 정하지 않은 사항
원본 보존 기간과 문서 삭제 권한자는 아직 정하지 않았습니다. 담당 부서의 확정된 정책이 나오기 전에는 임의의 보존 일수나 삭제 가능자를 안내하지 않습니다.

## 6. 용어
“현재”는 현재 승인된 판본이라는 문서 상태입니다. “확인 대기”는 문의가 접수되어 검토 전이라는 상태입니다. 두 상태 모두 모든 운영 권한을 뜻하지 않습니다.
