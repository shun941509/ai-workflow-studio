# 회의 결정 이력 RAG 실습 안내

ER-048의 가상 회의 원문과 meetings.json 원본 파일을 그대로 동봉합니다. 실제 검색에는 사용자가 선택한 원문만 들어가며 별도 JSON의 답을 모델에게 직접 제공하지 않습니다.

1. resources/practice/sample-input.json으로 질문과 검색어를 입력합니다.
2. 파일 선택에서 resources/er_048/document.md를 선택합니다.
3. 검색 인용과 최종 답변의 근거를 대조합니다. 검색 단어가 원문에 없을 때와 필요한 사실이 원문에 없을 때를 구분하세요.

이 자료는 원본 가상 연습자료이며 실제 모델 결과·정답 파일·고객 개인정보를 포함하지 않습니다. 검색어는 사용자가 지정하며 동의어·형태소·의미 검색이나 자동 재검색을 지원한다고 표현하지 않습니다.
