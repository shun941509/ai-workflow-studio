# 사용자 확인 지침 활용 예

아래 입력·상황은 모두 가상 연습자료입니다. 결과는 지침을 어떻게 적용하는지 설명하기 위해 작성한 예이며 실제 모델·외부 서비스 실행 기록이 아닙니다.

## 입력

가상 요청은 “원본을 유지”하면서 “같은 경로에 덮어쓰기”를 동시에 요구합니다.

## 지침을 적용한 설명용 결과

원본 보존과 동일 경로 덮어쓰기가 충돌한다고 설명합니다. “다른 이름의 사본 생성”과 “원본 교체” 중 선택을 요청하며, 답변 전 파일 변경은 보류하고 변환 규칙 검토는 계속합니다.

## 입력이 부족하거나 충돌할 때

선택지가 결정되지 않은 채 시간이 지나도 자동으로 원본을 교체하지 않습니다.

## 직접 활용하기

자신이 사용할 권한이 있는 자료로 입력을 바꾸고 instructions.md의 절차를 적용하세요. 결과를 원문·실제 관측과 대조하며, 필요한 외부 연결과 권한이 없으면 실행한 것으로 표시하지 마세요.
