# 가상 종이별 미리보기 모듈 — 부품 QX-120B

출처 ID: PART-QX-120B / 적용 부품 번호: QX-120B
원작 가상 소프트웨어 모듈 설명입니다. 실제 부품 수리 지침이 아닙니다.

## B1 기능과 증상
QX-120B는 이미 등록된 문서의 미리보기를 만드는 모듈입니다. 목록에는 항목이 있지만 미리보기만 보이지 않고 PREVIEW-WAIT가 표시되는 상황을 다룹니다.

## B2 절차
문서 ID와 원문 열기 가능 여부를 확인합니다. 원문은 열리지만 미리보기 상태가 처리 중이면 작업을 반복 생성하지 않습니다. 원문도 열리지 않으면 미리보기 장애로 단정하지 말고 원문 접근 확인 대상으로 분리합니다.

## B3 성공 확인
같은 문서 ID의 미리보기가 준비됨 상태이고 원문 제목과 일치하는지 확인합니다. QX-120A의 등록 대기 수를 이 모듈의 조치 기준으로 사용하지 않습니다.
