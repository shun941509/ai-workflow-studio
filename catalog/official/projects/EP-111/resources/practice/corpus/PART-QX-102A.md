# 가상 종이별 인덱스 표시 모듈 — 부품 QX-102A

출처 ID: PART-QX-102A / 적용 부품 번호: QX-102A
실제 제품이 아닌 원작 가상 예제입니다.

## C1 기능과 증상
QX-102A는 사용자가 선택한 목록 조건을 화면에 표시합니다. 항목이 저장돼 있지만 날짜 조건 때문에 화면에서 보이지 않는 경우를 다룹니다.

## C2 절차
화면의 기간·상태 조건을 기록한 뒤 조건 표시만 확인합니다. 기간 밖 항목인지 원문 생성일을 대조합니다. 기록된 조건과 맞지 않으면 화면 새로 읽기를 요청하되 원본을 수정하거나 삭제하지 않습니다.

## C3 식별 주의
QX-102A와 QX-120A는 숫자 순서가 다른 별도 모듈입니다. 코드가 일부만 주어지면 후보를 임의 선택하지 말고 전체 번호를 확인합니다.
