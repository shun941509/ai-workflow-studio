# 가상 종이별 보관 모듈 — 부품 QX-120A

출처 ID: PART-QX-120A / 적용 부품 번호: QX-120A
원작 가상 소프트웨어 모듈 설명입니다. 실제 기계 부품·고객 사례가 아니며 분해·수리를 지시하지 않습니다.

## A1 기능과 증상
QX-120A는 입력 문서의 이름을 보관함 목록에 등록하는 모듈입니다. 입력은 저장됐지만 목록에 나타나지 않고 QUEUE-HOLD가 보이면 등록 대기가 남았는지 확인합니다.

## A2 절차
읽기 전용 상태 화면에서 작업 ID와 등록 대기 수를 확인합니다. 대기 수가 0보다 크면 중복 등록을 시작하지 않고 기다림으로 기록합니다. 대기가 0인데 같은 작업 ID가 목록에 없으면 오류 코드와 작업 ID만 지원 요청 초안에 남깁니다. 원본 파일을 삭제하지 않습니다.

## A3 성공 확인
동일 작업 ID가 보관함 목록에 한 번 나타나면 등록 관측 완료로 기록합니다. 이 절차는 QX-120B나 QX-102A에 적용하지 않습니다. 보장 대기 시간과 지원 연락처는 미기재입니다.
