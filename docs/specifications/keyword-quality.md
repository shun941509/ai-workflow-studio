# 한국어 키워드 검색 진단

고정된 가상 정책 문서8개와 질문24개로 현재 운영 BM25 구현을 직접 실행했다. 질문·관련도 판정은 결과를 보기 전에 작성했으며, 답이 없는 질문4개도 포함한다. 이 작은 내부 진단 자료는 실제 고객 데이터의 대표성이나 출시 품질 인증을 보장하지 않는다.

## 실행과 관측

`node tooling/run-pnpm.mjs exec tsx tooling/evaluation/keyword-benchmark.ts`를 실행하면 `artifacts/evaluation/keyword-ko-latest.json`에 입력 데이터 SHA-256, 색인 manifest 해시, 알고리즘 버전, 질문별 순위·판정·지표를 기록한다. 모델 호출·네트워크 요청·미리 작성한 검색 결과는 사용하지 않는다. 자료의 usable/published 상태나 출시 증거도 변경하지 않는다.

2026-10-28 Node24.22.1, 상위3개 결과에서 다음을 관측했다.

|질문 종류|수|Recall@3|MRR@3|nDCG@3|관측|
|---|---:|---:|---:|---:|---|
|원문과 일치하는 단어|8|1.000|1.000|0.998|관련 문서 검색|
|대소문자·전각·구두점 정규화|4|1.000|1.000|1.000|NFKC와 단어 분리 적용|
|한국어 조사·형태 변화|4|0.000|0.000|0.000|원문 단어와 다르면 누락|
|뜻이 비슷한 자연어 표현|4|0.000|0.000|0.000|의미 검색을 제공하지 않음|
|전체 답변 가능 질문|20|0.600|0.600|0.599|정확 일치 질문만 잘 찾는 한계|

답이 없는 질문4개 중1개에는 검색 결과가 나왔다. 문서에는 고객 지원 시간만 있고 전화번호가 없는데 ‘고객 지원 전화번호’ 질문이 시간 안내를 회수했다. **검색 결과가 있다는 사실은 질문에 답할 근거가 있다는 뜻이 아니다.** 답변 가능성 검사와 답변의 주장별 근거 검증은 별도로 필요하다.

## 제품 적용

현재 편집기는 ‘키워드 검색’으로 표시하고 형태소·동의어·벡터·그래프 검색을 지원한다고 안내하지 않는다. 사용자에게 문서에 실제로 쓰인 검색어를 입력하도록 안내한다. 결과·인용은 원문에서 재구성하지만 의미적 답변 정확성을 자동 인증하지 않는다.

후속 Agentic·Hybrid·reranker·GraphRAG 구현은 동일 질문을 유지한 채 비교하고, 별도로 충분한 실제 분야별 평가자료를 확보해야 한다. 이 진단에 맞춰 판정이나 원문을 바꿔 점수를 높이지 않는다. 새로운 자료는 새 버전과 별도 해시로 추가한다. 전술한 기능의 출시 완료 여부는 실제 공급자·비용·권한·삭제·인용 시험과 함께 판단한다.
