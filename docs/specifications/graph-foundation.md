# GraphRAG 순수 계산 기반과 실행 지원 경계

`packages/rag-core/src/graph`는 파일·DB·네트워크·모델 SDK 없이 동작하는 그래프 자료 구조와 검색 계산이다. 이 코드의 존재는 Runner의 GraphRAG 지원이나 공식 예제의 실제 사용 검증을 뜻하지 않는다. `knowledge.graph`/`retrieval.graph` capability는 아직 활성화하지 않는다.

## 고정 근거와 자료 형식

추출 입력은 기존 불변 corpus/chunk 참조에 고정한다. 개체의 namespace/sourceIdentifier/version, 이름·별칭, 관계 끝점과 종류를 원문 UTF-8 바이트 범위·hash·인용과 함께 검사한다. 이름만 같은 개체를 합치거나 없는 버전을 최신으로 추정하지 않는다. 원문 범위를 벗어난 근거·다른 개체의 별칭·없는 끝점·잘못된 Unicode 경계·다른 corpus 참조를 거절한다.

`studio-explicit-graph-v1` 아티팩트에는 원본 추출 입력과 컴파일한 구조가 함께 있다. 열 때 전체 해시뿐 아니라 원본 근거와 재계산한 구조를 대조한다. 바깥 해시만 다시 계산한 위조 관계를 신뢰하지 않는다. 입력 객체의 이후 변경이 검증된 그래프를 바꾸지 않도록 snapshot을 소유한다.

## local 검색 계산

현재 접근권한 확인 뒤 실제 인접 관계를 제한된 폭 우선 탐색으로 따라간다. 방향·최대 hop·방문 개체·관계 검사량·경로 수·총 작업량·취소를 제한하며 원문 인용을 반환한다. 결정적인 최단 경로를 제공하는 범위이며 모든 가능한 경로를 찾았다고 표시하지 않는다. 접근권한 검사 전에 검색 이름의 모호성이나 다른 tenant의 개체 정보를 공개하지 않는다.

## 남은 R-22 연결

- Runner를 통한 실제 개체/관계 추출 모델 호출과 예산/취소/결과 검증.
- 실행 저장소의 불변 세대 작성·완료 후 활성화·재시작 복구.
- 현재 ACL/철회/tombstone과 모든 파생 결과 공개 경계.
- 커뮤니티 생성·근거 있는 요약·global 검색 및 모델 중계.
- 편집기 설정·실제 처리기/capability·ZIP 계약·공식 GraphRAG 예제.
- 실제 데이터의 검색/인용/유보 품질, 실제 모델과 호스트 검증.

## 내부 검증

R-01 재개 시 `tests/contracts/graph-artifact.test.ts`를 포함한 영향 4파일145시험이 통과했다. 실제 순수 계산으로 고정 바이트/근거·변조·접근권한·이름 충돌·방향/순환/상한·취소를 확인했다. 외부 모델 추출, Runner GraphRAG 실행, 커뮤니티/global 검색 성공의 증거는 아니다.
