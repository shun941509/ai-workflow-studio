# AI Workflow Studio — 확정 제품 범위

비전문가가 블록으로 AI 작업 순서를 만들고 운영용 ZIP을 내려받아 기존 AI 도구에서 실행한다. 관리자는 공식 예제를 검수·제공한다. 우선순위는 쉬운 제작, 안전한 실행, 소규모 운영이다.

## 사용자 승인과 범위

2026-10-28 사용자는 P2 상세 계획, 이어지는 P3/P4/예제/출시 계획을 마친 뒤 프로젝트 구축과 테스트까지 계속 진행하도록 승인했다. 외부 게시·배포·유료 서비스 생성·비밀정보 발급은 별도 권한과 실제 환경이 필요하다. 모든 구현 코드에는 역할·설계 이유·안전 경계를 설명하는 주석을 작성한다. JSON은 주석 문법을 넣지 않고 Schema description/$comment 또는 인접 문서를 사용한다.

## 정식 출시 범위

- 31개 블록과 공개한 각 실행 모드.
- 기본 RAG, Agentic RAG, Hybrid 검색과 reranker, GraphRAG local/global.
- Studio Runner 하나와 Codex/Claude Code/OpenCode 호스트 어댑터.
- 공식 프로젝트 EP-001~120, 공식 자료 ER-001~120의 실제 검증·게시 완료.
- Windows 우선. 정확한 런타임·호스트·OS 지원 조합은 검증 기록으로 관리.

## 운영용 정책

제품 UI/ZIP에 mock 모델, 가짜 결과, 개발 모드, 테스트 키, 내부 fixture, 개발 서버를 포함하지 않는다. 실제 연결 점검·권한·비용·오류·취소·복구 안내는 운영 기능이다. SKILL.md, 운영 코드, 템플릿, 실제 사용 샘플과 운영 하네스는 배포할 수 있다. 내부 verification.spec.json은 배포하지 않는다.

미완성 기능을 완료로 표시하지 않는다. 사용 가능한 capability만 Runner가 광고한다. 구현되지 않은 메뉴에 가짜 목록·기능 없는 성공 버튼을 채우지 않는다. 내부 개발 상태와 정식 공개 출시 상태를 구분한다.
